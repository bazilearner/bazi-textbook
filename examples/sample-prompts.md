# 三句可直接复制的提示词

> 所有提示词里的出生数据都是**虚构示例**，替换成你自己的即可。
> 技能触发靠的是「排八字／推演／看用神」这类词，用不着说「请使用某个技能」。

## 1. 教学式全流程（最推荐，本技能的核心用法）

```
帮我排 1990-05-15 14:20 出生的男命，按教科书方式一步步推：
起盘 → 定旺衰 → 取用神 → 辨格局 → 断岁运。
每一步都要写清「这一步在算什么、本例怎么算出来的、结果是什么」，最后出 PDF。
```

要点：出现「一步步／教科书／怎么算出来的」→ 走 `teaching-flow.md`（18—30 页）。

## 2. 结论式快报告

```
排一下 1990-05-15 14:20 男命，出一份结论先行的报告：
用神是什么、格局高低、近十年大运哪几年要留意，8 页以内。
```

要点：只要「结论／说清楚」→ 走 `report-blueprint.md`（8—12 页）。

## 3. 只看某一项

```
这个盘（庚午 辛巳 庚辰 癸未）帮我单独判格局：
月令透出什么、取什么格、顺用还是逆用、相神在哪一个字、成败六条逐条核。
```

```
只看旺衰：得令／得地／得生／得助四问逐条给依据，再给力量计分和口径。
```

```
看 2027—2036 的岁运：逐年列引动链（哪个关系 → 引动哪个字 → 落哪一宫 → 所主何事），标出峰值年。
```

## 4. 家庭合参

```
四个人的出生时间如下（…），做合参：只写相互之间的生克与宫位关系，不断吉凶、不预言离散。
```

要点：合参须写满 C(n,2) 对，`scripts/family.js` 会一次给出全部组合。

---

## 用之前先知道三件事

1. **性别必须说**。`paipan.js` 的性别参数缺省是「男」，女命漏说会得到反向的大运（脚本不报错）。
2. **出生地要说**。真太阳时校正要用经度，差 1 度约 4 分钟，足以跨时辰。
3. **23:00—24:00 出生要特别说明**。本技能采「一天没有两个子时」→ 日柱归次日。
