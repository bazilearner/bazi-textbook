## 一、表的用法（三步，别跳）

1. **定位**：以「日干 × 月支」查下表，得该月的**调候候补神**（一组，通常 1—5 个字）。
2. **定主辅**：看命局里这一组神**谁有谁无、谁多谁少**——
   - 命局中**缺**的那个，就是「不及」，是本次调候的**主用神**；
   - 命局中**已经过多**的那个，是「太过」，**必须舍去或抑之**（这正是打星号要提醒的地方）；
   - 组内有多字时，取「命中缺而月令宜有」者为第一顺位。
3. **与 L4 对表**：调候结论必须与「格局门、理法门、病药门」的取用一致。
   四门归一处的那个字，才是最终用神。**若调候与其余三门冲突，先回查日主强弱，再定取舍。**

> 《穷通宝鉴·五行总论》立表之旨：
> 「夫万物负阴而抱阳，冲气以和，过与不及，皆为乖道。故高者抑之使平，下者举之使崇，
> **或益其不及，或损其太过**。所以，贵于折衷，归于中道……行运亦如之，则命理之说，思过半矣。」

**「常法」与「修正」的关系（本技能最重要的一条纪律）**：
表给的是**常法用神**——它假定命局是普通的、均衡的。实战中必须按命局实际财官多寡修正。
**凡做了修正，报告里必须写出修正理由**，不许直接抄表当结论。
（范例：丁火生正月，常法「甲庚——庚金劈甲引丁」；但命局庚辛三见、金已太多，
再取庚则金多木折、坏印伤母，故**舍庚取丙**，改「甲丙」。此即《总论》「损其太过」之义。）

## 三、按季总则（表之外必须记住的气候逻辑）

表是「格」，总则是「理」。有冲突时以**月令气候**为大前提。

### 三春（寅卯辰）——寒木向阳，忌阴湿
- 春月木旺，调候关键在**火暖**与**水润**的配比：
  初春（立春—雨水）余寒未退，**专用丙火**，可少水；
  仲春（雨水—谷雨）阳气渐壮，**水火并用**（丙丁同功，不能无水）；
  暮春（谷雨后）阳壮木渴，**非水不可**，无水则根槁枝干。
- 春木见金：初春金气摧残木气，非上命；仲春木旺不妨用金，但须有土生金、有丁制金；季春木老，须庚金斲削。
- 春木见土：土为木之财，**少见则喜，多见则忌**（忌喧宾夺主）。

### 三夏（巳午未）——火旺木槁，调候为急
- 木：**最需要水**，得水为上格；忌火旺自焚；土宜**薄**不宜厚重（厚则财多身弱）。
- 土：**喜水滋润**（土润溽暑），忌旺火煅炼焦坼。
- 金：尤为柔弱，火多不畏（赖暗中湿土），**最宜见水**；土薄有用，土厚埋没无光。
- 火：**逢水制则免自焚**，见木助必招夭折；用金用土皆不可无水。
- 水：气势衰绝，**欲得比肩**（劫助），喜金生而忌火旺焰干。

### 三秋（申酉戌）——金神当权，木气内敛
- 木：先**丁**次**庚**（丁制庚、庚斲木，丁庚两全方成画戟）；秋木忌羌水（癸伤丁）。
- 火：性息体休，**得木生则有复明之庆，遇水克难免殒灭之灾**——秋火用官杀不可无印。
- 土：子旺母衰，**金多耗气、木盛制伏纯良**，三秋土性虚寒，**不能离火**。
- 金：当权得令，**火来煅炼遂成钟鼎之材，土多培养反惹顽浊之气**；见水则清神越秀，逢木则琢削施威。
- 水：金水澄清，**得金助则清澄、逢土旺而混浊**（戊土清平、己土浑浊）。

### 三冬（亥子丑）——天寒地冻，非火不化
- 木：**盘屈在地，寒木向阳**——最需要而不可缺者为**火**（重见不厌其多）；
  喜土培（宜戌未燥土，忌辰丑湿土）；金虽多不能克伐，水盛则冻木（反生为克）。
- 火：体绝形亡，**喜木生而有救，遇水克以为殃**；欲土制为荣，爱火比为利；见庚辛为难任财。
- 土：**惟喜火温**（寒谷回春）；水旺才丰、金多子秀、火盛有荣。
- 金：形寒性冷，**金不离官印**——土能制水而金体不寒，火来助土则子母成功。
- 水：司令当权，**遇火则增暖除寒**（此为最要）；金多反曰无义，木盛是为有情；
  土太过则势成涸辙，水泛滥则喜土堤防。

> 《穷通宝鉴》卷首「五行总论」原文可离线引用：
> 论木「**木性腾上而无所止，气重则欲金任使。木得金则有惟高惟敛之德**……
> 生木得火而秀，死木得金而造，生木见金自伤，死木得火自焚。」
> 论火「**火以木为体，无木则火不长焰；火以水为用，无水则火太酷烈。故火多则不实，火烈则伤物。**」
> 论土「土无常性，视四时所乘，**欲使相济得所，勿令太过弗及**。」
> 论金「金以至阴为体，中含至阳之精，乃能坚刚……**故金无火炼，不能成器**。」
> 论水「水不绝源，仗金生而流远；水流泛滥，赖土克以提防。**水火均，则合既济之美；水土混，则有浊源之凶。**」

## 四、常见「须修正」的情形（实战清单）

查表之后，遇到下列任何一种，**必须**改写常法用神，并写明理由：

| 情形 | 现象 | 修正方向 |
|---|---|---|
| **用神已在命中过多** | 表列之字，四柱已两三见、或通根得禄 | **舍之不用**，改取次神（损其太过） |
| **用神被合被克无救** | 主用神被邻干合去，或被忌神直克 | 改取**救应之神**；无救则该格降等 |
| **月令格局用神与调候冲突** | 如正印格而调候要财（财坏印） | 以**月令格局**为主线，调候降为辅助；若无可调和则直陈「格局有病」 |
| **从格 / 专旺** | 日主旺极或弱极，已成一方之势 | **弃调候常法**，顺其旺势取用（旺极宜泄、弱极宜克） |
| **气候已由他支补偿** | 如冬生而地支已聚火局 | 火的作用已足，转而补**次一位**（水/木） |
| **上下半月气候不同** | 五六月、十月、十一月、十二月（大暑/冬至/小暑为界） | 按**节气分界**两说并陈，取其与命局相符者 |
| **土王用事 / 人元用事** | 生于辰戌丑未月之气前若干日 | 兼看月令人元与调候，二者不一致时以**人元当令**为重 |

## 五、与脚本的配合

```bash
# 查表 + 自动标注「该神在命局中有无多寡」
node scripts/tiaohou.js lookup 庚 巳
node scripts/tiaohou.js check "庚午 辛巳 庚辰 癸未"     # 示例（虚构）
```

`check` 会输出：日干月支所对应的调候候补神；每个神在本命是**透干 / 藏支 / 全无 / 已成势**；
并给出「须修正」的初判提示。**它只做标注，不下结论**——结论仍由第 3、4 步的四门并参给出。
