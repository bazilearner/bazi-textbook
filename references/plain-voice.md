# 白话层与抚慰层 · 写作规范（把「算得对」变成「听得懂、用得上」）

> **本文件解决什么问题**：此前的报告能做到「推得清楚」，但**读起来像论文**——
> 术语密集、引文堆叠、开篇先讲经度与时辰边界，非研究型读者翻两页就放下了。
> 命理这件东西，价值有一半不在「算得准」，而在**被人理解、被人接住、知道下一步做什么**。
> 本文件把这一半固定成可执行的写法：**先给人话，再给依据；先给答案，再给推演。**

---

## 一、四层翻译：一句话要从原文走到动作

同一个判断，必须能走完这四层。**缺任何一层，读者就会卡住**：

| 层 | 写什么 | 例（虚构命例，仅示范格式） |
|---|---|---|
| ① 原文 | 经典原句＋书名篇名 | 《渊海子平》：「财多身弱，富屋贫人。」 |
| ② 白话 | 一句话说破，不用一个术语 | 钱财的事你经手得多，但**留不住**——像替别人看仓库。 |
| ③ 生活判断 | 落到他实际会遇到的场景 | 你容易被「看起来很大的机会」吸引，而自己的现金流扛不住那个体量。 |
| ④ 动作 | 一件现在就能做的事 | **先算能亏多少，再谈能赚多少**；大额合作一律留一个「退出条款」。 |

**纪律**：
- ②**不得引入①没有的判断**。若写白话时发现「这层意思原文没说」，是推演层漏了，回去补。
- ③必须具体到场景（钱、工作、家人、身体），**不能停留在性格形容词**。
- ④一件就够，**不要开清单**。清单等于没建议。

## 二、开篇总述：全篇第一页（必写，位置在封面之后、任何推演之前）

读者的耐心只有一页。这一页决定他读不读下去。

### 2.1 五段式（按序，总长 400—600 字）

| 段 | 内容 | 写法示例（虚构） |
|---|---|---|
| ① 一句话身份 | 用生活物象说清他的「质地」 | 「你是**一块被火烤着的铁**——底子硬，但一直有人在给你加温。」 |
| ② 主要矛盾 | 这张盘最要紧的那一处张力 | 「麻烦在于：你自己很硬，可周围的火与水一直在拉扯你，**力气用在哪，你自己说了不算**。」 |
| ③ 先回答问题 | **他问的那件事，直接给答案**（哪怕答案是「要看三年后」） | 「你问的换工作：**今年不宜裸辞，明年开春后有一步转机**。理由在第三章第三节，你可以自己核。」 |
| ④ 三条要点 | 靠什么／怕什么／什么时候顺 | 「靠**手艺与信用**；怕**替人担保**；**34—43 岁**这十年是最好的一段。」 |
| ⑤ 怎么读这份报告 | 给路径，不给压力 | 「想先看结论，翻到第六章；想看凭据，从第三章开始，一步一算。」 |

### 2.2 五条硬纪律

1. **不出现术语**。必须出现时**当句括注**：如「你的用神（就是最帮你、最该去靠的那一行）是水」。
2. **不写「根据子平法／四柱理论」**。读者不关心你的方法论，只关心他自己。
3. **不先讲排盘**。经度、均时差、时辰边界全部归附录，正文一句话带过：
   「以下按真太阳时 X 时 X 分起盘（详见附录 A）。」
4. **不吓人**。开篇不出现「凶」「克」「破」「孤」「夭」这类字；要讲风险，用「要留意」「别硬来」。
5. **不承诺**。不写「必发」「必胜」「一定离婚」；写「结构如此，条件满足时会这样」。

### 2.3 反例与正例

> **反例**（真实踩过）：「本命庚金生于巳月，失令而死，赖年干比肩、月干劫财透出……」
> ——读者第一句就被「失令而死」吓住，且完全不知道这跟自己有什么关系。

> **正例**：「你出生在初夏，火正当头。按老话讲，**你这类人像被炉火烤着的金属**：越炼越成形，
> 但也容易急、容易硬碰硬。好在你身边一直有同伴帮衬（年、月两个位置都有人），
> 真正的问题不是没人帮，是**帮的人和你一样硬**——所以要学会找「软一点」的办法。」

## 三、引文白译对照表（可直接取用，逐条标出处）

> 用法：正文引原文后，**紧接一句「也就是说……」**，从下表取白话。
> 表里没有的句子，**自己译，但必须译到「一个没读过命理书的人也能懂」**。

### 3.1 命与运：先把「命定」这层误解拆掉（开篇与末章最常用）

| 原句 | 出处 | 白话 | 用在哪 |
|---|---|---|---|
| 「命，好比是一辆新车……运，好比是这车要行驶的路。命是根据，运是环境；命是内因，运是条件。」 | 陆致极《命运的求索》 | 车出厂时的性能改不了，但**走什么路、什么时候上高速，是后来的事**。 | 开篇总述、解释「为什么同一个八字人生差别很大」 |
| 「命局是舟，大运是河……两岸的风景十年一变。」 | 王德峰《中国古代命理学要义》讲稿 | 船是船，河是河。**船小不怕，怕的是一直逆水**。 | 讲大运时给读者一个整体图景 |
| 「若把出生时间跟人生轨迹之间的这种对应关系，夸张为决定的或命定的关系，这就会导致宿命的看法，从而把命理学带上迷信的歧途。」 | 陆致极《中国命理学史论》 | 八字说的是**倾向与条件**，不是判决书。谁跟你说「注定」，谁就在骗你。 | 全篇定调；尤其用户问「是不是注定」时 |
| 「不知命，无以为君子也。」 | 《论语·尧曰》（王德峰讲稿引） | 知道自己是什么材料、什么节奏，**才不会把一辈子耗在追不属于自己的东西上**。 | 开篇结尾、末章收束 |
| 「无病不为奇，有药方为贵。」 | 病药说（《神峰通考》；此句为王德峰讲稿的申说之辞，非原书原文） | 八字有缺陷不是坏事，**有缺陷、又有补法的盘，反而更容易出头**；四平八稳的盘，多半平顺而不显。 | 讲「你的短板」时，先给这句垫底 |

### 3.2 断语类：给原文，也给人话

| 原句 | 出处 | 白话 | 注意 |
|---|---|---|---|
| 「财多身弱，富屋贫人。」 | 《渊海子平》 | 经手的钱多，**能留下的少**；看着场面大，自己手里紧。 | 不要说成「你会破产」；说「留存率是你要练的本事」 |
| 「伤官见官，为祸百端。」 | 《渊海子平》 | 才华外露的人碰上规矩多的环境，**容易顶撞、容易吃亏**。 | 落成「换一种表达方式」，不作灾祸预言 |
| 「金水伤官，人必绝顶聪明。」 | 通行断语（《渊海子平》《三命通会》皆有相近表述，非某一句原文） | 反应快、想得多、学东西快。 | 也要说代价：**想太多、睡不好** |
| 「旺极宜泄不宜克，弱极宜克不生。」 | 《滴天髓》 | 太强的时候要**给它出口**（不是硬压），太弱的时候要**顺着养**（不是硬补）。 | 讲用神时的分水岭 |
| 「伤相甚于伤用。」 | 《子平真诠·论相神紧要》 | 帮你「成事」的那个配角被打掉，比主角不在还麻烦。 | 解释「为什么某年明明是好运却卡住」 |
| 「八字用神，专求月令。」 | 《子平真诠·论用神》 | 先看你生在什么月份，**月份定了大的方向**。 | 讲取用第一步 |
| 「贵人驿马多升迁，常人驿马多奔波。」 | 梁湘润《子平基础概要》引经 | 同样一件事（跑动），**底子厚的人跑出机会，底子薄的人跑出辛苦**。 | 讲驿马时务必带这句，避免「驿马＝奔波命」 |
| 「华盖为艺术之星，主孤。」 | 《渊海子平·论华盖》引《壶中子》 | 有审美、有钻研劲，**喜欢一个人待着**。 | 「孤」要译成「独处的需要」，不能说「孤克」 |
| 「华盖重重，勤心学艺。」 | 《三车赋》（《神峰通考》引） | 这类人**在专业上肯下笨功夫**。 | 落到「适合深水区的手艺」 |
| 「天月二德扶持，利官少病」「众恶皆散」「百灾不为害」 | 《三车一览赋》《心镜赋》（《神峰通考》引） | 有一种「出事有人兜」的运气。 | 不作免死金牌，写「遇事容易有人帮，但仍要自己留余量」 |
| 「为人正大者，天乙生旺。」 | 《秘诀》（《神峰通考》引） | 天乙贵人不是「贵人」，更像**一种让人愿意帮你的气质**。 | 王德峰：关键时刻有人替你说一句话，而你并不认识他 |
| 「食神制杀」「羊刃驾杀」 | 《子平真诠》等 | 拿自己的**专业能力**去化解压力，是有本事的人才有的结构。 | 落到「你适合在压力大的行当里吃饭」 |

### 3.3 桃花、驿马、华盖的口语版（王德峰讲稿，可直接化用）

| 项 | 口语表述 |
|---|---|
| 桃花 | 有才气，多半在文艺、审美、表达上有点东西；**墙内桃花主夫妻恩爱，墙外桃花容易惹是非**。关键是落在哪一柱、有没有被冲。 |
| 驿马 | 一生奔走。命里没有、走到驿马运，也照样动；**动得好不好，看这步运是用神还是忌神**——用神运叫「马奔财乡，发如猛虎」，忌神运就是白辛苦。 |
| 华盖 | 艺术、宗教、哲思那一类气质；鲁迅「运交华盖欲何求」说的就是这个字。**旺而有气是才，衰而受冲是孤僻**。 |
| 天乙贵人 | 聪明，且**在关键处总有人替他说一句话**；这个人他未必认识。 |

## 四、神煞：该讲，但要讲对

> 用户的心理需求是真的——**听到「你有天乙贵人」和听到「你五行缺金」是两种感受**。
> 所以不能像早期版本那样一句「只作色彩」就打发掉。但也不能倒过来，拿神煞当主干。
> 分寸在这里：**先讲主干（五行用神），神煞作为「色彩与细节」补进去，并且讲清它的成立条件。**

### 4.1 三条纪律（都有出处，不是我的自创）

1. **神煞是辅佐，不是主干。**
   王德峰：「有的人看命，江湖术士背了一大堆神煞……从这个路子上去讲，**这个路子是不正的**。
   一个人的八字首先还是根据五行寻找用神，神煞的看法是辅佐性的。」
   → 报告里神煞**永远排在用神、格局之后**；先给结构，再上色彩。
2. **落哪一柱，决定它对哪一段人生说话。**
   梁湘润：「桃花在年柱，年柱主一至十五岁，这种幼年时期虽坐桃花，亦等于没有意义。」
   → 年柱 1—15（祖上、幼年）、月柱 16—30（父母、青年）、日柱 31—45（自己、配偶）、时柱 46 以后（子女、晚年）。
   → **不要把时柱的「孤辰寡宿」讲成婚姻警报**：那时候人本来就在收，梁湘润直说「并不须要重视」。
3. **成立与否，看四件事：坐旺坐绝、刑冲合会、空亡、被克。**
   - 坐旺（如乙卯为旺势桃花）征兆显；坐绝（辛卯为绝桃花）征兆不明。
   - **吉神逢冲／落空亡 → 空欢喜**；**凶煞逢冲／落空 → 转忧为喜**（王德峰：「一个凶神恶煞，结果它被冲了，好，就该被冲；或者落空亡被空掉，转忧为喜。」）
   - 贵人逢冲：帮你的人**不是一个人帮到底**，中途会换人（梁湘润）。
   - 凶煞若为日主五行所克，「反为我用」（梁湘润）。

### 4.2 常用神煞白话表（写报告时直接取一行）

| 神煞 | 古义（原文） | 白话 | 适合讲成什么 | 不要怎么讲 |
|---|---|---|---|---|
| **天乙贵人** | 「为人正大者，天乙生旺」（《秘诀》） | 关键时候有人替你说一句话，而你未必认识他 | 「你的运气里有一份『人情红利』」 | 不要写成「必有大官贵人扶持」 |
| **天德／月德** | 「天月二德扶持，利官少病」「众恶皆散」（《三车一览赋》《心镜赋》） | 出事容易有人兜；身体与是非都少一档 | 「你属于『摔了不容易骨折』的那类」 | 不要写成「百灾不为害」的免死金牌 |
| **文昌** | 即「食神得禄」（王德峰） | 读书、考试、写作、表达上的天分 | 「你靠脑子吃饭比靠体力吃饭顺」 | 不要许「必中」 |
| **学堂** | 「聪明命坐学堂」（《富贵赋》） | 学东西快，适合拜师、进学 | 「三十岁后回去读书，对你不是浪费」 | 与文昌不要重复堆砌 |
| **驿马** | 「贵人驿马多升迁，常人驿马多奔波」 | 一生爱动；动得好不好，看这步运是用是忌 | 「你适合在外地、在流动里找机会」 | 不要写「奔波劳碌命」 |
| **桃花** | 王德峰：带桃花者多有才气，墙内主夫妻恩爱，墙外易惹是非 | 有魅力、有审美；**位置比有无更重要** | 「你的桃花在月柱，是青年时期的人缘，不是婚外情」 | 绝对不用「烂桃花」「桃花劫」 |
| **华盖** | 「华盖为艺术之星，主孤」「华盖重重，勤心学艺」 | 有钻研劲，也需要独处 | 「你有一块只能自己待着的地方」 | 「孤」不许译成「孤克六亲」 |
| **将星** | 「有理想、有气度」（梁湘润） | 有主见、扛得住场面 | 「你适合做那个最后拍板的人」 | 不要写成「必掌兵权」 |
| **羊刃** | 「羊刃驾杀」 | 脾气硬，关键时候敢下狠手 | 「你的狠劲要用在事上，不要用在人上」 | 不要写「血光」「克妻」 |
| **孤辰／寡宿** | 「男忌孤辰，女忌寡宿」（俗说） | 喜欢独处、不爱应酬；**落时柱基本不必论** | 「你需要留白，不必强迫自己合群」 | 绝不写「克夫」「克妻」「主孤寡」 |
| **空亡** | 「空亡，一名天中杀」（《渊海子平》） | 有这个东西，但**不太落实**：名分有、实利薄 | 「这块是『有名无实』，别把力气全押上」 | 不要说「一场空」 |
| **劫煞／亡神** | 梁湘润：不遇对冲、三刑，又为日主所克者，终无大碍 | 容易被突发的事打断 | 「凡事留一个 Plan B」 | 不要写「凶死」「横祸」 |
| **金舆** | 「金舆者，乃禄命之旌旗」「主聪明多富贵」（《烛神经》） | 出行、车马、体面上的福气 | 「你在『移动』这件事上有福」 | 不要写成「必得豪车」 |

### 4.3 神煞段的写法模板（三句，一段一个）

> ① **有没有**：本命天乙贵人在日支（一个字）。
> ② **成不成立**：该支未逢冲、未落空亡，**成立**——所以这份「人情红利」是能用的。
> ③ **什么时候兑现**：逢申、子、辰年引动日支时最明显；若该年又逢冲，则「帮到一半换人」。
> ④（可选）**一句人话**：你不必刻意经营关系，**但别把人推开**。

**纪律**：一段最多讲三个神煞。**全列等于没讲**，读者只会记住「我命里好多星星」。

### 4.4 神煞禁语表

| 禁用 | 改成 |
|---|---|
| 孤克、克夫、克妻、克子 | 独立性强／需要独处／与伴侣节奏不同 |
| 夭折、短命、凶死、血光 | 该处要多留意（体检／出行／作息），并给具体观察项 |
| 绝后、无子 | 子女缘分晚／聚少离多（**且不断有无与数目**） |
| 破财、破产、必离 | 现金流要留余量／关系里要留沟通的口子 |
| 大凶、大劫、灾厄 | 高压窗口／需要提前安排的一段 |

## 五、抚慰层：让人读完有力量，而不是害怕

命理之所以被人需要，多半不是因为「准」，而是因为**在人说不清自己处境的时候，给了一套能说清的语言**。
所以报告的最后效果应该是：**他知道自己难在哪、知道那不是他的错、知道下一步做什么。**

### 5.1 四条原则

1. **命是结构，不是判决**（陆致极）。凡是「注定」，一律改写为「在这个结构下，条件满足时会……」。
2. **病药观**：先承认短板的价值——「无病不为奇，有药方为贵」。有缺陷、有补法的盘，往往比四平八稳的更出彩。
3. **把「凶」翻译成「要留意什么」**，并且**给出一个动作**。没有动作的风险提示，只会制造焦虑。
4. **给掌控感**：每讲一个不利面，紧跟一句「你能做的那部分是什么」。让他知道，**至少有一半在自己手里**。

### 5.2 三句话模板（讲难处时的固定顺序）

> **看见**：「这一处确实难——你不是想多了。」
> **归因**：「这不是你的错，是结构如此：你的力气都用在扛，没剩多少用来选。」
> **出路**：「结构给的路是：**把『扛』换成『挑』**——先减一件，再谈做好。」

顺序不能反。**先归因再给出路**，人才听得进去；一上来就给建议，等于否定他的处境。

### 5.3 严重项的写法（健康／婚姻／寿元，三处最需要克制）

| 项 | 必须做 | 禁止 |
|---|---|---|
| 健康 | 写**结构性病机**（如「金旺木弱，肝胆与筋腱是长期耗损处」）＋**年度可执行的检查项**＋「以现代医学为准」 | 诊断、用药、替代治疗、给出病名 |
| 婚姻 | 写**互动模式**（如「两个人都硬，争执起于不肯先软」）＋一条沟通建议 | 断离婚、断配偶长相职业、断「必有第三者」 |
| 寿元 | **不写年份**。只给「高关注窗口」与「该做的安排」（体检、保险、家人沟通） | 任何形式的死亡预言 |

### 5.4 结尾三件事（末章必写）

报告最后一页，读者手上要留下**三件具体的事**：

1. **今年可以做的一件**（小、具体、一周内能启动）。
2. **今年不要做的一件**（他最可能冲动去做的那个）。
3. **三年内要准备的一件**（为下一段运提前铺的路）。

三件事都要能对上正文的某一节（标「见第 X 章」），**不许凭空给建议**。

## 六、自检五问（出稿前逐条答，答不上就回去改）

1. **开篇 300 字内，有没有出现没解释的术语？**（有 → 改写成白话或加括注）
2. **全篇每个术语的第一次出现，有没有一句白话？**（抽查五个：用神、格局、得令、空亡、羊刃）

## 七、示范：一段完整的开篇（虚构命例，仅示范写法）

> 你是**一块被反复回炉的铁**：底子硬，也经得起敲，但这些年一直在被加温、被塑形，很少有机会自己决定要成什么样子。
>
> 你出生在初夏，火正当头。老话说「庚金生于巳月，失令而死」——翻成白话：**你的材料是金，可你落在了一个专门熔金的地方**。所以你从小就知道「硬扛」这件事，也比同龄人更能忍。
>
> 好在你不是孤军：年、月两个位置都站着和你同类的字，**一直有人跟你一起扛**。真正的麻烦不是没人帮，是**帮你的人和你一样硬**——一群硬碰硬的人凑在一起，事情推不动，情绪也下不来。
>
> 你问的那件事（要不要换个城市）：**今年不宜大动，明年开春后有一个可以走的窗口**。理由在第三章第五节，你可以拿年份自己核。
>
> 三句话记住这张盘：**靠手艺与信用吃饭；怕替人担保、怕把话说死；三十四到四十三岁是最好的一段。**
>
> 想先看结论，直接翻第六章；想看凭据，从第三章开始，一步一算。
>
> *（本段命例为虚构示例，不含任何真实命主信息。）*
