# 格局门 · 成败救应判据（《子平真诠》）

> 本文件是第 3—4 步「格局门」的可执行判据，**内置离线**。
> 底本：清·沈孝瞻《子平真诠》，徐乐吾评注。凡标「原文」者为可离线引用的原句；
> 未标者为本技能对该书体例的整理（判据化），非原文字句。

## 一、立格的第一句话（第 3 步的总纲）

> **原文**：「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。」

推论（本技能执行顺序）：
1. **先看月令**，不看别的。月令即「提纲」，是唯一的一等用神来源。
2. 月令本气透干 → 以透干之十神立格；本气不透 → 看**月令人元用事**当令之神
   （分野见 `relations-tables.md` 第五节）。
3. 四柱中月令以外透干之十神，**只能作「相神」或「忌神」，不能抢位立格**。
   —— 这是最常见、也最致命的判断错误。

**杂气月（辰戌丑未）特别说明**：
> **原文**（《论杂气如何取用》）：杂气用神，以**透干与会合**为准——四柱透出者取之，
> 不透而支会成局者取之；皆无，则取月令本气（土）。
> 「墓库逢冲则发」之说，任铁樵已斥为非：「墓库逢冲则发者，后人之谬也」。**本技能不采用。**

## 二、八格与顺用 / 逆用（这是格局门的核心操作）

> **原文**：「**财官印食，此用神之善而顺用之者也；杀伤枭刃，此用神之不善而逆用之者也。
> 当顺而顺，当逆而逆，配合得宜，皆为贵格。**」

| 格 | 类别 | 用神 | **顺／逆用** | 相神（辅用神者） |
|---|---|---|---|---|
| 正官格 | 四吉神 | 正官 | **顺用**（生之护之） | **财**（生官）、**印**（护官，制伤） |
| 财格 | 四吉神 | 财（正/偏） | **顺用** | **食伤**（生财）、**官**（护财，卫财） |
| 印格 | 四吉神 | 印（正/偏） | **顺用** | **官杀**（生印）、**比劫**（护印） |
| 食神格 | 四吉神 | 食神 | **顺用** | **财**（泄食生财）、**比劫**（护食敌枭） |
| 七杀格 | 四凶神 | 七杀 | **逆用**（制之化之） | **食神**（制煞）、**印**（化煞）、**刃**（合煞） |
| 伤官格 | 四凶神 | 伤官 | **逆用** | **印**（制伤）、**财**（泄伤生财） |
| 偏印（枭）格 | 四凶神 | 偏印 | **逆用** | **财**（制枭） |
| 阳刃格 | 四凶神 | 阳刃 | **逆用** | **官杀**（制刃） |

**读法要点**：
- 「顺用」的意思不是「好」，而是**顺着它的性子去养它**（如官要财生印护）。
- 「逆用」的意思不是「坏」，而是**必须给它一个对手**（如煞必须用食制或印化，无制则败）。
- **相神比用神更要紧**：
  > **原文**（《论相神紧要》）：「**伤用神甚于伤身，伤相甚于伤用。**」
  → 用了官而相神之财被劫，比官本身被克更严重。

## 三、成败总表（逐格照单核对，这是最实用的部分）

### 成
| 格 | 成的条件（满足其一即可，且无刑冲破害） |
|---|---|
| 正官 | 官逢**财生**（财生官）、或官逢**印护**（印制伤护官）；无刑冲破害 |
| 财 | 财生官旺；或财逢**食生**而身强带比；或财格**透印**而位置妥贴、两不相克 |
| 印 | 印轻**逢煞**（煞生印）；或**官印双全**；或身印两旺而用**食伤泄气**；或印多逢**财**而财透根轻 |
| 食神 | 食神**生财**；或食带煞而**无财**；或**弃食就煞而透印** |
| 七杀 | 身强**七煞逢制**（食制／印化／刃合） |
| 伤官 | 伤官**生财**；或伤官**佩印**而伤官旺、印有根；或伤官旺身弱而透**煞印**；或伤官带煞而无财 |
| 阳刃 | 阳刃透**官煞**而露**财印**，不见伤官 |
| 建禄月劫 | 透**官**而逢财印；透**财**而逢食伤；透**煞**而遇制伏 |

### 败
| 格 | 败的条件 |
|---|---|
| 正官 | 官逢**伤克**；或**刑冲** |
| 财 | 财轻**比重**（比劫夺财）；或财透而见**七煞** |
| 印 | 印轻**逢财**（财坏印）；或身强印重而透**煞** |
| 食神 | 食神逢**枭**（枭夺食）；或生财而**露煞** |
| 七杀 | 七煞**逢财而无制**（财滋弱煞 → 煞旺攻身） |
| 伤官 | 伤官**非金水而见官**（金水伤官喜见官，为例外）；或生财而**带煞**；或佩印而伤轻身旺 |
| 阳刃 | 阳刃**无官煞** |
| 建禄月劫 | **无财无官**，反透煞印 |

### 一句口诀（必背）

> **原文**：「**成中有败，必是带忌；败中有成，全凭救应。**」

→ 判读时的固定动作：
1. 先按上表定「成」还是「败」；
2. 若成，再找**带忌**在哪（哪一个忌神混进来了）；
3. 若败，再找**救应**在哪（哪一个字把病制住了）——**有救应则败格可救，贵气减而不失**；
4. 救应之神**被冲被合被克**时，反而是**破格之年**（用于应期）。

## 四、反直觉的两篇（最容易被坊间搞反）

### 《论四吉神能破格》
吉神（财官印食）用得**不当**同样破格。典型：
- 官格而**伤官**出现 → 破官。
- 财格身弱而比劫众 → 比劫「帮身」是好事，但**夺财**是坏事；此时比劫即「吉神破格」。
- 印格而**财**太旺 → 财本吉神，然坏印。
→ **结论：吉凶全在是否合于需要，不在名字好坏。**

### 《论四凶神能成格》
凶神（杀伤枭刃）用得**得当**反成大格。典型：
- 煞刃相合、煞刃两停 → **武贵**（《穷通宝鉴》：「二月阳刃驾煞，**煞刃暗合有情**」；
  《子平真诠·论四凶神能成格》亦以「煞刃两停」为凶神成格之例——**凶神用得当，即为贵格**）。
- 枭神而财制 → 格清。
- 伤官佩印 → 文贵。
→ **结论：同上。名字的好坏不等于作用的好坏。**

**这两篇是本技能四门并参时最常用来「纠错」的判据。**
凡遇到「命中明明凶神当道，此人却富贵」的情形，先查这两篇，而不是怀疑排盘。

## 五、用神的变化与纯杂（进阶，但应期必用）

| 项 | 判据 | 用法 |
|---|---|---|
| **用神变化** | 月令用神因**合、刑冲、会局**而变（如官被合、印被冲开） | 变则格亦变，前后两段人生格局不同 |
| **用神纯杂** | 用神一位为纯，两神并见为杂；**纯者贵，杂者庸** | 「两神成象」「两千不杂」皆从纯立论 |
| **格局高低** | 看**用神有力无力、相神有情无情、位置得所不得所** | 用来区分「贵」与「假贵」 |
| **因成得败 / 因败得成** | 成格的字恰好引出忌神；败格的字恰好制住忌神 | 用于判断「先好后坏」「先难后成」的时间序 |
| **生克先后分吉凶** | 同为克，**先克后生**与**先生后克**结果相反 | 判定同一年内事件的多空顺序 |

> 本技能提醒：`paipan.js` 输出的**十神表**只给「有无」，不给「先后」。
> **生克先后必须自己按四柱位置（年→月→日→时）逐对排**，并在报告里写出顺序。
> （同一命局中「某干之冲」与「某支之合、某支之破」常并存，即是先后问题，
> 须在报告里分先后叙述，不可混作一句。）

## 六、取运（大运怎么判，与格局配对）

口诀表（用神＋运的关系）：

| 格局 | 喜运 | 忌运 |
|---|---|---|
| 正官格（官为用，财印为相） | 财、印之地 | 伤、刃之地 |
| 财格（财为用，食伤为相） | 食伤、财之地 | 比劫夺财、煞攻身 |
| 印格（印为用，官煞为相） | 官煞、印之地 | 财坏印 |
| 食神格（食为用，财为相） | 财、食之地 | 枭夺食 |
| 七杀格（煞为用，食/印为相） | 食制煞（身旺）／印化煞（身弱） | 财滋弱煞、煞无制 |
| 伤官格（伤为用，印/财为相） | 佩印（身弱）／生财（身旺） | 无制之伤、伤见官（非金水） |
| 阳刃格（刃为用，官煞为相） | 官煞制刃、财生官煞 | 再见刃、见伤官 |
| 建禄月劫 | 财、官、食伤 | 比劫叠见 |

> **原文**（《子平真诠·论行运》）：「论运与看命无二法也。看命以四柱干支，配月令之喜忌，
> 而取运则又以运之干支，配八字之喜忌。故运中每运行一字，即必以此一字，配命中干支而统观之，
> 为喜为忌，吉凶判然矣。」
>
> → **本技能的应期做法即由此而来**：不把大运当独立命局看，而是把运的干支**放进命局里重看一遍**，
> 看它是否新增了关系、是否补上了相神、是否伤到了用神。

## 七、外格用舍（特别格的取舍）

> 原文（《论外格用舍》）：外格只有「**月令无用神可取**」时才论。月令有用神，一律按正格走。

本技能的特别格清单（仅在月令确实无用可取时启用，且须满足「一气成象」）：
- 从格：**从财、从杀、从儿（从食伤）、从势**
- 专旺格：**曲直仁寿**（木）、**炎上**（火）、**稼穑**（土）、**从革**（金）、**润下**（水）
- **阳刃倒戈、羊刃驾煞、煞刃两停**（实为阳刃格之变，非独立外格）
- 特殊成形：**木火通明、金水伤官、金白水清、财煞相生、伤官驾煞、食神制煞、藤萝繁甲、灯花拂剑**

**真从 / 假从的分判**（最易出错，务必按此四条）：
1. **月令是否有微根**——未月甲木，未为木库，月令有微根 → **不作真从**，只作「财多身弱」（富屋贫人）。
2. **阳干从气、阴干从势**——「阳干从气不从势，阴干从势无情义」；
   阳干（甲丙戊庚壬）从格条件严于阴干。
3. **从格须纯粹**——见一点印比即为破格，立成「假从」。
4. **化气须见辰**——「化气必须见辰，方为真化」（《穷通宝鉴》明言，且注明系本书独有之发明）。

**本技能纪律**：凡拟断「从格」，必须在报告中**列出上述四条逐条核对的结果**，
并说明「若按正格论会得出什么不同结论」。**不得只写「此造从财」了事。**

## 八、宫位配六亲（落地的接口）

> 原文（《论宫分用神配六亲》大义）：**年为祖上父母，月为父母兄弟，日为妻（夫）己身，时为子女。**

用法（本技能第 6 步落地时按此定位）：
- 某十神**落在哪一柱**，就主该柱所主之人；该柱被冲／被合／被刑，即该人应事。
- **日柱为「己身＋配偶」**；时柱为「子女＋晚年」；月柱为「父母＋事业根基、兄弟」；年柱为「祖上＋幼年」。
- 十神**有无／多少／旺衰**判该六亲的存续与得力程度；
  **十神的性情与能力取向**为中可靠度；**性别与数目**为低可靠度（见 `judgment-core.md` 第三节）。

**用神看子星的古法**（《穷通宝鉴》明文，与俗法「官为子」不同）：
以**生用神者为妻（夫），用神本身为子**。
例：用庚者，土妻金子（财为妻、官煞为子）；用丁者，木妻火子（比劫为妻、食伤为子）。
**本技能只据此判「子息有无与迟速」，不断性别。**
