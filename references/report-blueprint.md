## 一、章节清单（按此顺序写，共 12 节 + 附录；第 11 节条件触发）

### 第 0 节 · 边界与口径声明（**必写，放最前**）
- 出生地经度、与 120°E 的经度差、均时差、三口径时刻表（北京时／平太阳时／真太阳时）。
- **距时辰边界的秒数**。≤20 分钟 → 双盘并出。
- 用户报出的四柱 vs 真太阳时口径的四柱是否一致；若不一致，**明确指出差异在时柱**。
- 23:00—24:00 出生 → 按 `zi-shi-dayroll.md` 第〇节准则**判归次日**，写明裁决过程与采用的日柱日主（不再双盘并列）。

### 第 1 节 · 骨架（两盘共有的「不变量」）
- 日主强弱（得令／得地／得生／得助／被克泄耗，逐项写）。
- 格局：月令本气/人元用事 → 何格。
- **用神五档写全**：用神 / **相神** / 喜神 / 忌神 / **闲**。
  - **相神不可省**——《子平真诠·论相神紧要》「伤相甚于伤用」。写成「用甲、喜丙丁」这种三档表述，
    会把相神抹平，进而导致大运吉凶判反（已实测踩过）。
  - **闲**指不助不伤而略有益者（如寒湿之局的燥土戌未）。
  - 同五行之内**还要分阴阳**：木取甲（阳木可为丁火之薪）不取乙；火取丙不取丁（丁为比肩，
    与日主同类不充相神，且须耗印为薪）。
- 五行计数**必须声明口径**（推荐：干 1／支本气 1／余气 0.5），并**禁止重复计数**
  （地支本气与藏干是同一物）。
- **两盘一致的部分**写在这里；分歧项移到附录。

### 第 2 节 · 四门并参（交叉验证）
四小节，每小节都写出推理过程：

| 小节 | 依据 | 必写内容 |
|---|---|---|
| 调候 | `tiaohou-table.md` | 表列常法用神 → 本命太过多寡 → **是否修正、为什么** |
| 格局 | `geju-chengbai.md` | 立格 → 顺/逆用 → **相神是谁** → 成/败 → 带忌或救应在哪 |
| 理法 | 第 1 节强弱 | 气势偏于哪一端；是否触发「旺极宜泄／弱极宜克」的例外 |
| 病药 | `judgment-core.md` | 「病」落在哪一行（雕枯旺弱）；「药」是什么（损益生长） |

→ 四门若不一致，**回第 1 节重取用神**，不许挑一个喜欢的当结论。

### 第 3 节 · 生克制化 与 刑冲合害会
- 先列出命局四柱**本身已有**的全部关系（合／冲／刑／害／会／半合／拱夹／暗合）。
- 判定该命是**「静盘」还是「动盘」**。静盘者，一切事件必由运年引动——此结论直接决定第 5 节。
- 三刑全的年份单列，只写「某三支三刑全」，**不写刑的名目**。

### 第 4 节 · 十二长生 · 旬空 · 神煞
- 十二长生：只作**根气强弱的辅助量**，不作旺衰主判。
- 旬空：指出哪一柱地支落空、空掉的是哪一位十神 → 该事物「有而不实」的取象。
- 神煞：只列`relations-tables.md`第七节「有五行根据」的那一批；**明写「只作色彩，不定吉凶」**。

### 第 5 节 · 岁运应期
- **先给大运定性，再算流年**。大运定性走 `judgment-core.md` 第八节的**四层权重**：
  ① 用神／相神是否到位 → ② 日主是否得根 → ③ 调候燥湿寒暖 → ④ 冲刑合害。
  **顺序不可颠倒**——把 ④ 当主题是判大运最常见的错误。建议直接出「大运四层评分表」。
- 大运干支逐一与命局求关系（用 `paipan.js rel`），**地支层与天干层都要看**：
  天干层＝五合（合去/羁绊）、相冲、**争合**（一字被两处合，力分）。
- 流年在运之上再叠一层，找**新增关系**、**凑齐的三合/三会/三刑**，
  以及**填实大运所拱之字**（虚拱逢填实，常是整运的峰值之年）。
- 冲克到某十神的位置 → 该位六亲的应期；**同期另一十神转旺 → 另一位六亲安好**，一消一长必须同时成立。
- 「静盘」（命局本身无冲无刑无害）→ 一切事件由运年引动；但**不可**因此把「第一个新关系」
  当成该十年的主题（那是第 ④ 层）。

### 第 6 节 · 十神六亲
- 按宫位（年祖上／月父母兄弟／日妻己身／时子女）逐一落位。
- 可靠度分级下笔：**有无多少旺衰＝高**；性情能力＝中；**性别与数目＝低（不断）**。
- 子息用「生用神者为妻、用神为子」定有无迟速，**不断男女**。

### 第 7 节 · 富贵穷通
- 以格局高下立论（用神有力无力、相神有情无情、位置得所不得所）。
- 特别提示两类常见象：**「财多身弱·富屋贫人」**（财旺而不任）、
  **「伤官佩印／煞刃两停／金水伤官」**等成格之贵。
- **不下「必富」「必贵」「必然破产」这类绝对断语**；写「财之性情」与「财富留存能力」。

### 第 8 节 · 性情
- 依据（可离线引用原文）：五行配五常——**水智、火礼、木仁、金义、土信**；
  「金水伤官，人必绝顶聪明」；「曲直成格，必主仁寿」；
  「火性炎上，生居东南，果断有为；若居西北，谨畏守礼」。
- 再叠加：日主十神（食伤吐秀／官杀拘身／印星内敛／财星务实）、用神被伤的性情反噬。
- 写法：**三到五条具体特征**，每条注明由哪个字的什么状态推出。

### 第 9 节 · 疾病
- 依据 `judgment-core.md` 第四节的结构性病机（金旺木折／火弱水寒／土弱不制水／火郁成局）。
- **必须写明**：「五行类象是传统文化类比，不是诊断；以现代医学检查与治疗为准。」
- **不给用药、不给替代治疗建议。** 只给「高关注窗口」与可执行的观察项（体检、作息、决策节奏）。

### 第 10 节 · 出身地位
- 以年柱（祖上、幼年）、月柱（父母、根基）为据；看该二柱的十神、旺衰、是否受冲克。
- 只作**倾向性描述**（家境的厚薄、早年得不得荫、是否离乡——驿马逢冲即离乡之象），
  **不写具体职业、职务、金额**。

### 第 11 节 · 多版本比对与分歧裁决（**条件触发**：同一命盘已有另一份推演时）

走 `SKILL.md` 第 9 步的四步法：逐项对照 → 分歧定名 → 各自复算 → 回到原文裁决。本节必写：

| 内容 | 要求 |
|---|---|
| 两版交集 | 先公布**完全一致的条目**——这就是可靠性证据，不能省 |
| 分歧裁决表 | 列「项／A 版／B 版／裁决／依据」，**依据必须是可引用的原文** |
| 自己判错处 | **明写「我错了哪一步、错在哪条规则」**。不写清错在哪，等于没有裁决 |
| 口径类分歧 | 命宫、阴干羊刃、三刑名目等**流派不一而又非主线**者，**只列口径、不作判据** |
| 修正回写 | 裁决结果回写 `judgment-core.md` 案例档案，并留「重跑检查清单」防再犯 |

### 附录 A · 分歧项（单列待验）
- 边界命例：另一口径盘的差异要点（至少点明日主与时柱差异、由此改变的冲合/羊刃/六亲/神煞）。
- 晚子时：另一流派日柱及其重排结果。
- 上下半月气候不同者：两说并陈。
- 这些**只列不判**，或在有实证时用事实反推。
- **口径类分歧另记一节**：命宫（14 减法／脚本算法互异）、阴干羊刃（有无两说）、
  三刑名目（古本与通行本互倒）——**同属「只列口径不作判据」**。

### 附录 B · 可证伪的自设观察项（**必须写，且必须是真的可证伪**）
- 给 2—3 条未来可用现实检验的具体命题（如「某年是否确有异地迁移」「留存率是否长期低于经手规模」）。
- 目的：让读者能反过来校验这份推演的可靠性。

### 附录 C · 精度自述
- 必须引用：梁湘润《八字务实研究》专章讨论「八字的准确率究有多少」，
  这类学问的精度上限约「十之六七」，**凡声称百发百中的都不可信**。

## 二、全篇固定纪律（每条都要落到文字上）

1. **结论先行，依据在后**；每条断语标出它落在 L4 的哪一步（定强弱／取用神／辨格局／定喜忌）。
2. 命中已知事实，**注明「事后验证」**，不得表述为「事先预测成功」。
3. 健康、婚姻、寿元：明写「**民俗参考，以现代医学/法律/实际生活为准**」。
4. **不预言死亡年份**，不给「必死于某年」。只给「高关注窗口」＋可执行观察项。
5. **不断子女性别、不断手足数目。**
6. 凡引用经典原文，**标明书名与篇名**；凡属本技能的整理或经验，**标「本技能」**，不冒充古人。
7. 四门并参若出现分歧，**分歧要写进报告**，不许隐藏后只给一个结论。
8. **报告本身可以写命主的真实信息（那是交付物）；但技能文件不得留档**——
   任何示例、注释、复盘记录都只能用虚构数据或结构描述。见 `SKILL.md` 开头〈第一条维护纪律〉。

## 二之二、定稿前必跑的「数字自洽复核」（30 秒，能挡掉绝大多数硬伤）

报告写完，**逐条拿脚本输出对一遍**，对不上就回去改，**不要凭记忆**：

| # | 核什么 | 怎么核 | 常见错法 |
|---|---|---|---|
| 1 | 四柱 | `paipan.js chart "<出生>" <性别>` | —— |
| 2 | **时柱与日主是否匹配** | 用 `relations-tables.md` 第十节**五鼠遁**表验「日干 × 时支」 | **晚子时换日后沿用旧时干**（如 `甲申` 日写 `丙子`，甲日必 `甲子`） |
| 3 | **大运方向与起运** | 脚本的「起运 X 年 Y 月 Z 天」＋运干支序列 | **顺逆反了**（阳男阴女顺／阴男阳女逆），起运随之差好几年 |
| 4 | 大运年段 | 脚本给的「起止年／年龄」**逐运照抄** | 按「十年一桶」自行分桶 → 整体错位一格 |
| 5 | 五行计数 | 声明口径后与脚本 `五行：` 一行比对 | 本气与藏干重复计数 |
| 6 | 关系运算 | `paipan.js rel "<四柱>"` 逐项对（**含拱合与天干层**） | 漏拱合；漏天干合／冲／争合 |
| 7 | 调候落点 | `tiaohou.js check "<四柱>"` | 时柱改了却不重查 → 主神「有力／全无」判反 |
| 8 | 时柱边界距离 | `truesolar.py` 的**三口径距离全写** | 只挑真太阳时一个（最贴界的往往不是它） |
| 9 | 跨盘合计 | 合参的五行合计／全盘偏少项**只算一次、多处引用** | 同一数字在正文与附录出现两个版本 |
| 10 | 合参覆盖 | `family.js` 输出的 **C(n,2) 全部对**逐一落地 | 漏掉某一对（如夫妻对） |
| 11 | 内部一致性 | 正文结论与附录表格是否互相打架 | 同一张盘的大运在「本篇」与「合参章」不同 |

> **铁律：凡脚本能算的，一律以脚本为准，报告不得手算**——四柱、大运、起运、关系、五行、
> 调候落点全部归脚本。手算只用于**判读**（强弱、格局、用忌、应期）。**排盘层一旦手算，必错。**

## 三、输出（PDF）

```python
import sys
sys.path.insert(0, "<skill>/scripts")     # Windows 用反斜杠绝对路径
import pdfkit
pdfkit.register_fonts()                   # 已内置 Windows/macOS/Linux 字体候选 + ttc 子字体
S = pdfkit.styles()
doc, story = pdfkit.make_doc(OUT, "标题", footer_left="页脚左", footer_right="页脚右")
story += [pdfkit.table(rows, widths), pdfkit.kv_box("小标题", [("要点", "说明")], width)]
doc.build(story)
```

- 用 `pdfkit`（reportlab）。**不要用 weasyprint**（UOS 上常因 pango 版本错配直接报错）。
- `<font color=...>` 的颜色值**必须带 `#`**；Canvas 上用 `drawString` 不是 `text`。
- 首屏用 PageTemplate 的 cover 模板，正文切 body 模板（`NextPageTemplate` + `PageBreak`）。
- 生成后用 pypdf 抽查页数与文字层可否提取。
- 交付前把关键页渲染成图目视检查一次（表格是否溢出、中文有无方块）。
