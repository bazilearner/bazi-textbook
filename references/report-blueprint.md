# 报告蓝图（七章骨架 + 每章写法 + 数据来源）

> **一句话**：先给**人话与答案**，再给**盘面**，再带他**走五步**，最后**回到他的问题**。
>
> 本文件保证：**在完全没有外部知识库的情况下，本技能仍能产出一份结构与深度达标的报告。**
> 每一章都标出「依据哪个内置文件」「数据从哪个脚本来」「必须写与不许写什么」。
> 直接当大纲逐项打勾，不会漏项。
>
> **配套**：白话与抚慰的写法见 `references/plain-voice.md`（术语首现即译、引文必附白话、
> 神煞怎么讲、禁语表）；细致式的颗粒度见 `references/detail-style.md`；
> 教学式的推导顺序见 `references/teaching-flow.md`。**三份文件不冲突：本文件管「章的顺序」，它们管「每章写到多细」。**

## 零、开工前的四件事（顺序不能颠倒）

| # | 动作 | 命令 / 依据 | 产物 |
|---|---|---|---|
| **0** | **问清他要什么**（见 §0.2） | 五问清单 | 报告的主题、要回答的问题、读者是谁 |
| 1 | 排盘 | `paipan.js chart "<日期时间>" <性别>` | 四柱、十神、藏干、纳音、长生、旬空、胎元命宫身宫、五行计数、神煞、大运、流年 |

| 3 | 调候查表 | `tiaohou.js check "<四柱>"` | 调候候补神 + 命中落点 + 太过/不及提示 |

> `geju-chengbai.md`（格局成败）、`judgment-core.md`（内核与案例）、`zi-shi-dayroll.md`（晚子时）、

### 0.2 第 0 步：五问（**必须在动笔前问，答不上就按合理假设先写、并在报告里声明假设**）

| # | 问什么 | 为什么问 | 不问他也要写进去的默认值 |
|---|---|---|---|
| 1 | **你现在最想问哪一件事？**（工作／钱／感情／家人／身体／要不要搬／要不要换） | 决定**卷首给什么答案**、第六章回应什么 | 默认：整体运势与近三年节奏 |
| 2 | **是想听结论，还是想看推演过程？** | 决定切**结论式**还是**教学式**（见 SKILL.md 第 8 步） | 默认：结论式；若对方用了「细致／一步步／为什么」等词，切教学式 |
| 3 | **近三年有没有已经发生的大事？**（换工作、搬迁、亲人变故、生病） | 用来做**事后验证锚点**，校准应期判断 | 无则跳过，不影响出稿 |
| 4 | **这份报告给谁看？**（自己／家人／朋友） | 决定第二人称与措辞尺度（给长辈看要更缓） | 默认：给本人看，用「你」 |
| 5 | **有没有已有的一份报告或结论要核对？** | 触发第 9 步「多版本合并与分歧裁决」 | 无则跳过 |

**纪律**：用户没说清的，**按默认值写，并在卷首第一行声明**：
「你问的是 X；若你其实想问 Y，第六章的框架可以直接换题目重排，前面五章不用重算。」

## 一、全篇架构：七章（按此顺序写，一页都不许提前）

| 章 | 标题 | 回答什么 | 篇幅（结论式） | 关键要求 |
|---|---|---|---|---|
| **卷首** | **一页纸：先说结论** | 你是谁、你问的事怎么办 | 1 页 / 400—600 字 | **不出现术语**；先答案后依据 |
| **第一章** | **你是怎样一个人** | 白话画像 + 三条要点 | 1—2 页 | 物象比喻 + 靠什么／怕什么／何时顺 |
| **第二章** | **八个字读给你听** | 盘面：四柱、五行、十神、神煞 | 2—3 页 | **每一项都带一句白话**；神煞按 `plain-voice.md` §4 写 |
| **第三章** | **一步步推给你看** | 五步推导链（起盘→旺衰→用神→格局→岁运） | 4—8 页 | 每步：人话结论 → 推法 → 过程 → 原文 → 白译 |
| **第四章** | **分项细读** | 性情、六亲、事业财、健康 | 3—5 页 | 每项落到场景，不给死断语 |
| **第五章** | **时间表：哪十年、哪一年** | 大运定性 + 流年应期 | 2—3 页 | 每运给「可做／慎做／必做」三则 |
| **第六章** | **回到你的问题** | **逐条回答他的提问** + 三件事 | 1—2 页 | 与卷首答案一致，不许改口 |
| 附录 A—E | 边界、观察项、分歧、精度、术语表 | 给较真的人 | 2—3 页 | 见 §3 附录 |

> **为什么把「问题」放在首尾两处**：读者翻开要答案（卷首），合上要行动（第六章）。
> 中间四章是**给不放心的人准备的凭据**——他可以随时跳过去核，也可以完全不看。

## 二、逐章写法

### 卷首 · 一页纸：先说结论（**必写，位置在封面之后、任何推演之前**）

五段式，严格照 `plain-voice.md` §2.1 写：

1. 一句话身份（物象比喻）；
2. 主要矛盾（一句话）；
3. **先回答他的问题**（哪怕答案是「要看三年后」）；
4. 三条要点：靠什么／怕什么／什么时候顺；
5. 怎么读这份报告（给路径）。

**禁止**：术语、经度、均时差、时辰边界、「根据子平法」。这些一律进附录 A，正文一句带过。

### 第一章 · 你是怎样一个人（白话画像）

- 承卷首，用**三段**把画像说完整：**质地**（日主＋月令）→ **处境**（旺衰＋最旺与最缺的那两行）→ **活法**（用神与格局指向的生存方式）。
- 收尾给一张 **术语对照小表**（3—6 行，只列本篇出现过的词），格式见 `plain-voice.md`；
  「用在本篇指什么」必须落到**本盘的字与位**，不能写通用解释。
- **不许**在这一章报数字、报干支表（那是第二章的事）。

### 第二章 · 八个字读给你听（盘面）

| 小节 | 写什么 | 来源 | 白话要求 |
|---|---|---|---|
| 2.1 四柱表 | 年月日时四柱、十神、藏干、纳音、长生、旬空 | `paipan.js` / `detail.js` | 表下加一句「这张表怎么读」：横着是四段人生，竖着是五行关系 |
| 2.2 五行分栏 | 五行五栏（天干／支本气／藏干／合计） | `detail.js` | 声明**粗口径**（看多少）；一句人话点出「最多的一行、全无的一行」意味着什么 |
| 2.3 十神配置 | 十神统计、缺哪一位 | `detail.js` | 每个出现的十神给**一句性格白话**（见下 §2.3 表） |
| 2.4 神煞 | 只列本命实有的，按 `plain-voice.md` §4.3 三句式写 | `paipan.js` | **每段一个神煞，最多三个**；必须写「成立与否」 |
| 2.5 刑冲合害会 | 逐类核，含「无」 | `detail.js` | 只说「哪两处力量在互相拉扯」，不铺术语 |

#### 2.3 十神一句白话（可直接取用）

| 十神 | 一句白话 | 落到报告里的说法 |
|---|---|---|
| 比肩／劫财 | 和你一样的人：同伴、同行、竞争者 | 「你身边不缺同类，缺的是能给你不同意见的人」 |
| 食神 | 你会享受、也会创造的那一面 | 「你适合把兴趣做成手艺」 |
| 伤官 | 你不服管、也不肯将就的那一面 | 「你的才华要配一个容得下你的环境」 |
| 正财 | 靠劳动与积累来的钱 | 「一分耕耘一分收获，这条对你成立」 |
| 偏财 | 靠机会与人脉来的钱 | 「你能碰到机会，但留不留得住另说」 |
| 正官 | 规矩、责任、名分 | 「你在有规矩的地方最能立住」 |

| 偏印 | 偏门学问、直觉、独处 | 「你想事情的路子和别人不一样」 |

### 第三章 · 一步步推给你看（五步推导链）

**这一步的报告组织，按 `references/teaching-flow.md` 走**；本章只固定「每步的四件套」：

| 每步必须给 | 写法 |
|---|---|
| ① **一句人话结论** | 先给结果，不用术语：「你的力气，够用但不算厚。」 |
| ② **推法**（在算什么） | 「这一步量的是：出生那个月，是帮你还是耗你。」 |
| ③ **过程**（可复算） | 四问逐项、计分表、算式；数字一律照抄脚本 |
| ④ **原文 + 白译** | 引一句经典，紧跟一句「也就是说……」；白译取 `plain-voice.md` §3 |

**五步与脚本的对应**（照抄，不要手算）：

| 步 | 内容 | 供货 |
|---|---|---|
| 1 起盘 | 四柱、大运、真太阳时校正 | `paipan.js` / `truesolar.py` |
| 2 定旺衰 | 得令／得地／得生／得助、克泄耗、力量计分 | `wangshuai.js` |
| 3 取用神 | 调候／理法／病药／格局四门并参 → 用·相·喜·忌·闲 | `tiaohou.js` + 手判 |
| 4 辨格局 | 月令透出、取格、顺逆、相神、成败六条 | `geju.js` |
| 5 断岁运 | 四层权重定性 → 引动链 → 兑现年份 | `suiyun.js` |

**用神五档写全**（不可省相神）：
用神 / **相神（标门）** / 喜神 / 忌神 / **闲**。
《子平真诠·论相神紧要》「伤相甚于伤用」——写成「用甲、喜丙丁」这种三档，会把相神抹平，
进而导致大运吉凶判反（已实测踩过）。

> **凡称「相神」必标门**：写「格局门·相神 X」或「调候／扶抑门·辅神 X」。
> 详见 SKILL.md〈相神门类纪律〉。

**五行计分两套口径，各自声明，不可相加、不可互相核对**：
粗口径（干 1／支本气 1／藏干各 0.5）看「多少」；细口径（干 1／日干本体 1／支本气 1／中气 0.5／余气 0.25、月支×2）看「强弱」。

### 第四章 · 分项细读（每项都要落到场景）

| 节 | 必须写 | 不许写 |
|---|---|---|
| **4.1 性情** | 3—5 条具体特征，每条注明由哪个字的什么状态推出；五行配五常（水智火礼木仁金义土信）可引 | 「你性格内向」这类无依据的标签 |
| **4.2 六亲** | 按宫位（年祖上／月父母兄弟／日配偶己身／时子女）落位；可靠度分级（有无多少＝高，性情＝中，**性别数目＝不断**） | 断子女性别、数目；断配偶职业长相 |
| **4.3 事业与财** | 以格局高下立论（用神有力无力、相神有情无情、位置得所不得所）；写「财之性情」与「留存能力」 | 「必富」「必贵」「必然破产」 |
| **4.4 健康** | 结构性病机（雕／枯／旺／弱）＋年度可执行检查项＋「以现代医学为准」 | 病名、用药、替代治疗 |
| **4.5 神煞细读**（**单设一节，回应「想听星星」的心理需求**） | 每个神煞：有没有 → 在哪个柱（哪一段人生）→ 成立与否（坐旺／逢冲／空亡）→ 何时兑现 → 一句人话 | 只列名字；用禁语（孤克／克夫／血光） |

### 第五章 · 时间表：哪十年、哪一年

- **先给大运定性，再算流年**。四层权重（`judgment-core.md` 第八节）：
  ① 用神／相神是否到位 → ② 日主是否得根 → ③ 调候燥湿寒暖 → ④ 冲刑合害。
  **顺序不可颠倒**——把 ④ 当主题是判大运最常见的错误。
- 每步大运给 **「可做／慎做／必做」三则**（写法见 `guidance-style.md` 组件四）。
- 流年在运之上叠一层：找**新增关系**、凑齐的三合／三会／三刑、**填实大运所拱之字**（虚拱逢填实＝峰值之年）。
- **静盘**（命局本身无冲无刑无害）→ 一切由运年引动；但**不可**把「第一个新关系」当成该十年的主题。

### 第六章 · 回到你的问题（**必写，报告不写这一章等于没交付**）

| 结构 | 写法 |
|---|---|
| **6.1 你的问题清单** | 把第 0 步收到的问题**原话列出**（1—3 条），一条不漏 |
| **6.2 逐条回答** | 每条：**结论**（能／不能／什么时候）→ **依据**（见第几章第几步）→ **条件**（满足什么才成立） |
| **6.3 三个动作** | 今年可以做的一件 / 今年不要做的一件 / 三年内要准备的一件；**每条标「见第 X 章」** |
| **6.4 一句收束** | 用「不知命，无以为君子」一类的话收住——**知命不是认命，是知道劲往哪儿使** |

**纪律**：
- 第六章的结论**必须与卷首一致**。若中途推演推翻了卷首的判断，**回去改卷首**，不许两处打架。
- 不许在第六章引入前三章没出现过的新判断（读者会以为你临时编的）。
- 不许给医疗、投资、法律的具体建议，只给「结构与动作方向」。

## 三、附录 A—E

### 附录 A · 边界与口径声明（**必写，放最后**，正文只在卷一语带过）

- 出生地经度、与 120°E 的经度差、均时差、三口径时刻表（北京时／平太阳时／真太阳时）。
- **距时辰边界的秒数**。≤20 分钟 → 双盘并出，分歧项在此列出。
- 用户报出的四柱 vs 真太阳时口径的四柱是否一致；若不一致，明确指出差异在时柱。
- 23:00—24:00 出生 → 按 `zi-shi-dayroll.md` 第〇节准则**判归次日**，写明裁决过程与采用的日柱日主。
- 两套计数口径、六档表的分层说明（相神取格局义、喜神取扶抑义）。

### 附录 B · 可证伪的自设观察项（**必须是真的可证伪**）

- 给 2—3 条未来可用现实检验的具体命题（如「明年是否确有异地迁移」「留存率是否长期低于经手规模」）。
- 目的：让读者能反过来校验这份推演的可靠性。

### 附录 C · 多版本比对与分歧裁决（**条件触发**：同一命盘已有另一份推演时）

走 SKILL.md 第 9 步四步法：逐项对照 → 分歧定名 → 各自复算 → 回到原文裁决。必写：

| 内容 | 要求 |
|---|---|
| 两版交集 | 先公布**完全一致**的条目——这就是可靠性证据 |
| 分歧裁决表 | 「项／A 版／B 版／裁决／依据」，依据必须是可引用的原文 |
| 自己判错处 | **明写「我错了哪一步、错在哪条规则」** |
| 口径类分歧 | 命宫、阴干羊刃、三刑名目：只列口径、不作判据 |

### 附录 D · 精度自述

- 必引：梁湘润《八字务实研究》专章讨论「八字的准确率究有多少」，
  这类学问的精度上限约「十之六七」，**凡声称百发百中的都不可信**。
- 另可引陆致极：把出生时间与人生轨迹的对应关系**夸张为决定关系，就会走上迷信的歧途**。

### 附录 E · 术语对照总表

- 本篇出现过的全部术语，一列：术语 / 一句白话（≤20 字）/ 在本篇指什么。
- 与第一章的小表的区别：第一章只列**开篇用到的**，这里列**全篇**。

## 四、全篇固定纪律（每条都要落到文字上）

1. **结论先行，依据在后**；每条断语标出它落在哪一步（定强弱／取用神／辨格局／定喜忌）。
2. **术语首现即译**；**每条引文后跟一句「也就是说……」**（见 `plain-voice.md`）。
3. 命中已知事实，**注明「事后验证」**，不得表述为「事先预测成功」。
4. 健康、婚姻、寿元：明写「**民俗参考，以现代医学/法律/实际生活为准**」。
5. **不预言死亡年份**，不给「必死于某年」。只给「高关注窗口」＋可执行观察项。
6. **不断子女性别、不断手足数目。**
7. 凡引用经典原文，**标明书名与篇名**；凡属本技能的整理或经验，**标「本技能」**，不冒充古人。
8. 四门并参若出现分歧，**分歧要写进报告**，不许隐藏后只给一个结论。
9. **报告本身可以写命主的真实信息（那是交付物）；但技能文件不得留档**——
   任何示例、注释、复盘记录都只能用虚构数据或结构描述。见 `SKILL.md` 开头〈第一条维护纪律〉。

## 五、定稿前必跑的「数字自洽复核」（30 秒，能挡掉绝大多数硬伤）

报告写完，**逐条拿脚本输出对一遍**，对不上就回去改，**不要凭记忆**：

| # | 核什么 | 怎么核 | 常见错法 |
|---|---|---|---|
| 1 | 四柱 | `paipan.js chart "<出生>" <性别>` | —— |
| 2 | **时柱与日主是否匹配** | 用 `relations-tables.md` 第十节**五鼠遁**表验「日干 × 时支」 | **晚子时换日后沿用旧时干**（如 `甲申` 日写 `丙子`，甲日必 `甲子`） |
| 3 | **大运方向与起运** | 脚本的「起运 X 年 Y 月 Z 天」＋运干支序列 | **顺逆反了**（阳男阴女顺／阴男阳女逆），起运随之差好几年 |
| 4 | 大运年段 | 脚本给的「起止年／年龄」**逐运照抄** | 按「十年一桶」自行分桶 → 整体错位一格 |
| 5 | 五行计数 | 声明口径后与脚本 `五行：` 一行比对 | 本气与藏干重复计数 |
| 6 | 关系运算 | `paipan.js rel "<四柱>"` 逐项对（**含拱合与天干层**） | 漏拱合；漏天干合／冲／争合 |
| 7 | 调候落点 | `tiaohou.js check "<四柱>"` | 时柱改了却不重查 → 主神「有力／全无」判反 |
| 8 | 时柱边界距离 | `truesolar.py` 的**三口径距离全写** | 只挑真太阳时一个（最贴界的往往不是它） |
| 9 | 跨盘合计 | 合参的五行合计／全盘偏少项**只算一次、多处引用** | 同一数字在正文与附录出现两个版本 |
| 10 | 合参覆盖 | `family.js` 输出的 **C(n,2) 全部对**逐一落地 | 漏掉某一对（如夫妻对） |
| 11 | 内部一致性 | **卷首结论 vs 第六章回答 vs 正文判断**三处是否一致 | 卷首说「明年可动」，第六章说「三年内不宜」，自相矛盾 |
| 12 | 可读性 | 抽卷首与第六章各 300 字，数一数有几个**没解释的术语** | 开篇就上「失令而死」，读者当场弃读 |

> 调候落点全部归脚本。手算只用于**判读**（强弱、格局、用忌、应期）。**排盘层一旦手算，必错。**
