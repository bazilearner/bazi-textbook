# 细致式（教学式）全流程推演 · 章节骨架与详尽度标准

> **本文件解决什么问题**：`report-blueprint.md` 给的是**结论式**客户报告模板（11 节 + 3 附录，
> 单人 8—12 页），它「结论先行、依据在后」，但**不展示推法、不给分层明细、不逐对列生克**。
> 于是遇到「用户要一份细致、全面、把排八字全流程说清楚的报告」时，照那份模板写出来的东西
> 会显得**薄**——不是内容错，是**颗粒度与过程展示不够**。
>
> 本文件定义第二种交付样式：**教学式（细致式）**。它是结论式的**超集**：
> 结论式有的它都有，另外多出「推法／过程」「分层分栏明细」「逐对生克」「逐类核（含无）」
> 「密集引原句」「用神落地建议」这些层。
>
> **触发条件**：用户说「细致」「全面」「把全流程说清楚」「像教材那样」「每一步都要有过程」
> 「排八字怎么排的要写出来」——一律用本样式。
>
> ---
>
> ⚠ **先读 `teaching-flow.md`（教学式五步推导链）再读本文件。**
> 本文件（`detail-style.md`）管「**有哪些节、每节要放到多细**」——
> 它是按**知识模块**排的（盘面基础／四门并参／六亲／岁运……）。
> `teaching-flow.md` 管「**节与节之间是什么推导关系**」——它是按**推导顺序**排的：
> **起盘 → 定旺衰 → 取用神 → 辨格局 → 断岁运**。
> **教学式报告的实作顺序：先用 `teaching-flow.md` 排推导链，再用本文件的栏位清单填颗粒度。**
> 若时间紧、只能读一份，读 `teaching-flow.md`。

## 一、总体要求：每一节都要回答三问

**只给结论的报告，达不到「细致」。** 细致式的每一节都必须自带三样：

| 序 | 必须回答 | 反例（结论式常见写法） |
|---|---|---|
| 1 | **这一节在算什么**（推法／依据哪本书哪条规则） | 直接给结果，不说算法 |
| 2 | **本例怎么算出来的**（过程写清，读者能跟着算一遍） | 只写「大运逆排」不写数到哪个节、几天、除几 |
| 3 | **结果是什么**（结论） | —— |

**过程要写到「可复算」**：给数字的地方给出算式（如「距上一节 24 天，24 ÷ 3 = 8，故 8 岁起运」）；
给判断的地方给出条文（如「《论印绶》：印轻逢财，印格败也」）。

## 二、篇幅与颗粒度基线（硬指标）

| 项 | 结论式（report-blueprint） | **细致式（本文件）** |
|---|---|---|
| 单人篇幅 | 8—12 页 | **18—30 页** |
| 四柱怎么来的 | 直接给四柱 | **每柱给「推法 → 本例推算过程 → 结果」三栏**（年以立春、月以节＋五虎遁、日查万年历、时以日干起时干） |
| 时辰边界 | 报三口径时刻 | **三口径表（口径／计算过程／所得时刻／归属时辰）** ＋ 两口径差异**逐条列出** ＋「骨架变不变」的结论 |
| 大运 | 四层评分表 | 四层评分表 ＋ **起运推算过程** ＋ 每运十神 ＋ 逐年 |
| 五行计数 | 一行五个数字 | **五栏表：五行／天干／地支本气／藏干／合计＋判断** |
| 十神 | 干十神一行 | **配置表（位置／干支／干十神／支藏干十神）＋ 十神统计 ＋「十神不全」的讨论** |
| 生克制化 | 常被省略 | **逐对列出**（作用／具体表现／对命局的影响） |
| 刑冲合害会 | 只列出现的 | **逐类核，含「无」**（六合／三合／三会／六冲／刑／六害／相破／天干层，各注明有无） |
| 十二长生 | 报四个宫位 | 逐支报 ＋ **宫意解释** ＋ 有无禄刃的结论 |
| 旬空 | 报空哪支 | **写明推算过程**（日柱属何旬）＋ 落点 ＋ 含义 |
| 神煞 | 列名目 | **带查法**（神煞／查法／落点／解读） |
| 四门并参 | 一张总表 | **一门一小节**，各引经典原句，**展示「常法」与「扶抑」的冲突及修正理由** |
| 理法门 | 一句话 | **七维检查表**：五行气势／流通与阻滞／衰旺／中和／寒暖燥湿／清浊／体用 |
| 病药门 | 一句话 | **四病逐条判（成病／不成病）＋ 四药逐条取用** |
| 用神结论 | 五档 | 五档 ＋ **落地**（方位／行业／颜色／作息） |
| 引文 | 少量 | **每个关键判断都附经典原句并标书名篇名** |
| 岁运 | 大运评分 | 大运评分 ＋ 近年流年细看 ＋ **关键节点归纳（最佳窗口／需防守／远期提示）** |

## 三、章节骨架（逐节栏位清单，直接当大纲打勾）

### 0. 推演对象与所用资料
性别／出生（公历＋时刻）／地点（＋经纬度）／所用底本（四门各对应哪本书／哪一版）／口径声明

### 3.1 第一步：排四柱与大运
- **3.1.1 四柱推法**（表：柱 ｜ 推法 ｜ 本例推算过程 ｜ 结果）
  四柱四行，每行必须写出该柱的规则要点：年以**立春**为界（非正月初一）；月以**节**为界（非中气）＋**五虎遁**定月干；
  日**查万年历**；时先定**时支**（按钟点）再以**日干起时干（五鼠遁）**。
- **3.1.2 时辰边界核验**（表：口径 ｜ 计算过程 ｜ 所得时刻 ｜ 归属时辰）——三口径：北京时间／地方平太阳时／真太阳时；
  给出**距边界秒数**；**如实说出分歧**；**逐条列出两口径的差异**（少哪个神煞、少哪个藏干、少哪组合、多个什么）；
  最后给「**骨架变不变**」的结论（年月日三柱动没动、日主强弱／格局／用神／喜忌变没变）。
- **3.1.3 大运与起运**：**写清方向如何定**（阳年男／阴年女顺，阴年男／阳年女逆）与**起运怎么算**
  （顺行数到下一节、逆行数到上一节，天数 ÷ 3 = 年数，余数折算月日）；再给大运表（大运 ｜ 起止年 ｜ 年龄 ｜ 十神 ｜ 吉凶倾向）。
- **3.1.4 旬空、命宫、胎元**：各写**推法**（旬空＝日柱所在旬；命宫＝按生月生时起命宫法；胎元＝月柱天干进一位、地支进三位）。
  命宫属**非主线项**，只列口径不作判据。

### 3.2 第二步：盘面基础（L1—L3）
- **3.2.1 五行分布**：五栏表（五行／天干／地支本气／藏干／合计）＋ 判断列 ＋「最旺／最弱／全无之行」的结论
- **3.2.2 十神配置**：配置表 ＋ 十神统计 ＋ **「十神不全」讨论**（缺的十神对应哪一方面有所欠缺，须靠后天补足——属结构性描述，不作吉凶）
- **3.2.3 生克制化**：**逐对列出**（作用／具体表现／对命局的影响）；每条都要回答「该作用对用神是有益还是受损」
- **3.2.4 刑冲合害会**：**逐类核，含「无」**；最后给**盘性判定**（静盘／半动盘／动盘）与其实务含义
- **3.2.5 十二长生**：逐支 ＋ **宫意** ＋ 有无禄刃之地
- **3.2.6 旬空**：推法 ＋ 落点 ＋「有而不实」的取象
- **3.2.7 神煞**：表（神煞／查法／落点／解读）＋「只作色彩」的纪律重申
- **3.2.8 定旺衰（★ 教学式核心必写，按 `teaching-flow.md` 第三节）**——把「身强身弱」拆成可数的四问：
  - **① 得令否**：先写**旺相休囚死的推法**（以月令五行为「我」：当令旺、令生相、生令休、克令囚、令克死），
    再写日主在此月的实际位置（旺／相／休／囚／死）与**得令／失令**的判定。
  - **② 得地否**：逐支列「支／藏干（十神）／日主同类之根／根的力量」四栏；
    结论落到**本气根（根深）／中气余气根（根浅）／无根**三档；另报禄位、刃位、墓库。
  - **③ 得生否**：印星落点逐项列（透干／本气／中气／余气）；结论落三档。
  - **④ 得助否**：比劫落点逐项列；结论落三档。**附记**「比肩不充相神」「阴干比肩力弱」两条精微规则。
  - **⑤ 克泄耗**：官杀／食伤／财 三类各几处、在哪些位置（判断「能不能任财官」的原料）。
  - **⑥ 力量计分**：**先声明口径**（干 1／日干本体 1／支本气 1／中气 0.5／余气 0.25；月支 ×2），
    逐字列「基础分｜是否月令加权｜得分｜归类」，给出同类合计、异类合计、**同类占比**与判定线。
  - **⑦ 四问汇总**：表（问／答／要点）＋ **综合判定** ＋ **两法互校**（四问与计分是否同向；
    背离时**明写以「月令＋有无本气根」为准**，并写取舍理由）。
  - **⑧ 两条例外**（必写）：《滴天髓》「旺极宜泄不宜克，弱极宜克不宜生」——从格／专旺的门槛，
    并**把裁决推到第三步**，声明本节只给「常法之强弱」。
  - **供货**：`node wangshuai.js all "<四柱>" "<生辰>"`（另有 `deling|dedi|desheng|dezhu|kexie|score|summary|bazi` 各子命令）

### 3.3 第三步：四门并参（L4）
- **3.3.1 调候门**：引《穷通宝鉴》原文 → 常法 → **与扶抑的冲突** → **修正结论与理由**
- **3.3.2 理法门**：**七维表**（五行气势／流通与阻滞／衰旺／中和／寒暖燥湿／清浊／体用）＋ 核心判断 ＋ 治法
- **3.3.3 格局门**：表（环节／判断／依据）——取格／顺逆／成败／救应／相神／格局高低，逐环给条文
- **3.3.4 病药门**：**四病逐条判**（雕／枯／旺／弱，各注「成病／不成病」）＋ **四药逐条取用**（损／益／生／长）
- **3.3.5 辨格局（★ 教学式核心必写，按 `teaching-flow.md` 第五节）**——把「格局门」一条链走到底，
  并把**生克制化、刑冲合害**一并落到「成格／破格」上（它们不是独立一节，是成格的运算法则）：
  - **① 月令透出什么**：表（月支藏干／十神／是否透干／透于何处／另通根于他支）＋ **人元司令**（节后第几日→当权之神）。
    **取格规则要分两路写清**：四生（寅申巳亥）四正（子午卯酉）**先看司令**（透干＝格显／不透＝藏用）；
    四库（辰戌丑未，杂气）**以透干与会合为准**；月支＝日主**禄位／刃位**者走**建禄格／月刃格**（于月令之外求用）。
  - **② 取格**：写「→ 定格：X格」并给依据条文；若另有可作格神的透干字，**并列列出并裁决**（不可两说并列而不裁）。
  - **③ 顺逆用**：四吉神（财官印食）**顺用**、四凶神（杀伤枭刃）**逆用**，引《论用神》原句；
    并必写**反直觉两篇**（《论四吉神能破格》《论四凶神能成格》）——**名字的好坏不等于作用的好坏**。
  - **④ 相神**：按格给相神候选（官格以财或印为相、杀格以食或印为相……），逐字列命局实况并标出候选字；
    落点写清「透干（力显）／本气／中气／余气」；**相神缺位则写「格不成，须待运年补出」**（这是第五步的伏笔）。
  - **⑤ 成败检查（逐条核，含「无」）**：① 用神本身是否被冲被合；② 用神透干处是否被合被冲；
    ③ 忌神是否当道（带忌）；④ 相神有无与是否被伤；⑤ 地支层关系；⑥ **天干层关系（最易漏：五合／相冲／争合）**。
    最后照四条判定口径给结论（成格／格败／待运补相／破格）。
  - **⑥ 格局高低与盘性**：「有情、有力无力」四问；**盘性三档互斥**（动盘／半动盘／静盘）＋自检一问。
  - **供货**：`node geju.js all "<四柱>" "<生辰>"`（另有 `touchu|quge|shunni|xiangshen|chengbai|sixiong`）

### 3.4 第四步：四门归一 · 用神与喜忌
四门并排表（入口／经典／所得结论）→ **用·相·喜·忌·闲五档** → **落地：方位／行业／颜色**

### 3.5 十神六亲（L5）
表（六亲／星或宫／本命情况／解读）＋ 可靠度分级 ＋ 子息古法（只论有无迟速，不断男女）

### 3.6 富贵穷通
用神有力否／相神有情否／位置得所否／纯杂 → **总评**（不下绝对断语）＋ 一句实务提醒

### 3.7 性情
表（来源／表现）＋ 合看小结

### 3.8 疾病（传统五行类象，非医学诊断）
表（五行状态／传统对应脏腑／偏向提示）＋ **传统调养方向（仅供参照）** ＋ **必须强调：不是医学结论**

### 3.9 出身地位
表（柱／宫位／星象／解读）＋ 综合结论

### 3.10 岁运应期
**引动链表**（关系／作用双方／被引动之字／该字十神／落宫／所主事项——这是「大运流年**如何引动命局**」的直接答案，
由 `suiyun.js` 供货）＋ 大运表（大运／年份／十神／吉凶／具体判断，每运给一段可读的判断）
＋ **填实虚拱检查**（虚拱逢填实即成局＝峰值之年）＋ **近年流年细看**（流年／干支／与命局大运的作用／判断）
＋ **关键节点归纳**（最佳窗口／需防守／远期提示）＋「这是节奏参考，不是事件预告」。
**纪律**：大运定性走**四层权重**（用／相到位 → 得根 → 调候 → 刑冲合害只作色彩），
引动表属**第④层**，**不得当作该运的主题**。

### 3.11 边界说明
表：关于时辰／关于精度／关于流派分歧／关于健康／关于用途——逐条说清

## 五、出稿前自查（细致式专有）

0. **（教学式）五步是否齐、顺序是否对**？起盘 → 定旺衰 → 取用神 → 辨格局 → 断岁运，
   每步是否都有「推法／过程／结果」三问？——**详细清单见 `teaching-flow.md` 第八节（六条）**。
1. **三问是否每节都答**了（推法／过程／结果）？凡只给结果的节，补过程。
2. **明细表是否逐栏齐全**？五行五栏、十神统计、生克逐对、逐类核（含「无」）、神煞查法、
   **定旺衰四问＋计分、取格透干对照＋成败六条**——缺一即不达细致。
3. **引文密度**：每个关键判断是否附了经典原句并标篇名？至少四门并参每门一条原文。
4. **过程可复算否**？凡出现数字（起运岁数、距边界秒数、计数合计、**同类占比**），是否给了算式？
5. 「无」的项是否也写出来了（如「三会：无」「忌神：无」）？——**只列「有」的，读者无法核；
   列出「无」的，读者才知道你核过了。**
6. 落地建议（方位／行业／颜色／调养方向）是否给出？并在同一处重申其限定语。
7. 边界说明是否独立成节（时辰／精度／流派／健康／用途）？
8. **（教学式）岁运章是否给了「引动链」表**（关系 → 被引动之字 → 落宫 → 所主 → 十神）？
   四层权重是否按序走、刑害是否只作色彩？填实虚拱是否核了？
