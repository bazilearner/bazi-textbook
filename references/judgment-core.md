## 二、L4 有四个入口，四部经典各管一门（不是四个流派）

| 门 | 经典 | 入手处 | 核心 |
|---|---|---|---|
| 格局 | 《子平真诠》 | 月令藏干 | 定格局 → 顺逆用 → 成败救应 → 相神 |
| 调候 | 《穷通宝鉴》 | 出生月份的气候 | 十干 × 十二月查表，取调候之神 |
| 理法 | 《滴天髓》 | 全局气势 | 旺极宜泄不宜克，弱极宜克不宜生 |
| 病药 | 《神峰通考》 | 先诊病再下药 | 雕枯旺弱四病、损益生长四药 |

**四门归一**：都是在找一个能让八字回到「中和」的字。
证据：《滴天髓阐微》道光四年程芝云序——「神峰以损益病药立说……**及观《滴天髓》，然后知其论之所本**」；
徐乐吾——「《滴天髓》是树顶的硕果，《子平真诠》是摘取硕果的阶梯」。

关键原文：
- 《子平真诠·论用神》：「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。」
- 任铁樵《体用》：「旺则抑之，如不可抑，反宜扶之；弱则扶之，如不可扶，反宜抑之。此命理之真机，五行颠倒之妙用也。」
- 《穷通宝鉴》卷首《五行总论》：「……或益其不及，或损其太过。所以贵于折衷，归于中道。」

| 十神 | 六亲（男） | 备注 |
|---|---|---|
| 比肩 | 同性手足、同侪 | 日主自身即一位比肩 |
| 劫财 | 异性手足 | |
| 食神 / 伤官 | 晚辈、才华、女命子女 | |
| **正财** | **妻**（正配） | |
| **偏财** | **父**；异性缘 | |
| **正官** | **女**（正官为女）、职位、名望 | |
| **七杀** | **子**（七杀为子）、压力、魄力 | |
| **正印** | **母**、学历、文书、贵人 | |
| 偏印（枭） | 继母、偏门学问、悟性 | |

**可靠度分级（本技能的核心方法纪律）**：
- **高**：有无、多少、旺衰、得用与否（如「官星藏于时支」→ 子女晚得）
- **中**：六亲的性情与能力取向
- **低**：**子女性别**。实测常不验——本技能的经验是：**官杀只见其一，而实际子女同一性别；
  且其中一位的出生之年恰落在另一十神当值**，两头都对不上。**故不要用命理断子女男女**。
- **低**：手足的准确数目与长幼。以月柱为兄弟宫、月支藏劫财为异性手足之根，只作取象，
  不可当判据。现代实务中多不以此立论。

## 四、疾病取象（五行配脏腑）

| 五行 | 脏腑/体 |
|---|---|
| 木 | 肝胆、筋、眼、神经、**风** |
| 火 | 心、小肠、血脉、舌、神志 |
| 土 | 脾胃、肌肉 |
| 金 | 肺、大肠、皮毛、**骨** |
| 水 | 肾、膀胱、**骨**、耳、脑髓、津液 |

常见结构性病机的组合（用 L4 的语言说，就是「失衡极点落在哪两行」）：
- **金旺木折**：金多克木 → 肝木郁而风动 → 中风、眩晕、筋惕
- **火弱水寒**：心阳不足 + 寒湿内停 → 血行不畅、寒湿着于关节（痹、痛风）
- **土弱不制水**：湿浊泛于下焦 → 关节肿痛
- **火郁成局**：火欲成而未成 → 血压骤升

**纪律**：五行类象是传统文化类比，**不是诊断**。报告必须写明「以现代医学检查与治疗为准」，
且不给出用药或替代治疗的建议。

## 五、神煞怎么用

任铁樵《知命》痛骂：「至于奇格异局、神煞纳音诸名目，**乃好事妄造，非关命理休咎**」，
并引刘伯温《千金赋》：「吉凶神煞之多端，何如生克制化之一理」。

**取舍原则**：
- 只取**有五行根据**的：天乙贵人（日干见某支）、文昌（食神得禄之位）、禄神、羊刃、驿马（三合局之冲）、
  华盖/将星（三合局之墓与旺）、孤辰寡宿（年支推）、国印贵人（本气之克）。
- 只作**辅助色彩**，不单独定吉凶。断语优先级永远低于 L4。
- 《子平真诠·论四吉神能破格》：「格局既成，即使满盘孤辰入煞，何损其贵？

## 七、边界命例处理法（必做）

出生时辰落在**时辰边界 ±20 分钟**内，必须：
1. 用 `truesolar.py` 算真太阳时，并**显式报告距边界的秒数**；
2. 北京时间、地方平太阳时、真太阳时三种口径各排一盘；
3. **只采用两盘（或多盘）共有的结论**——这部分是「骨架不变量」；
4. 分歧项单列，标注为待验，或在有实证（已发生的六亲/健康/事件）时用事实反推。

**重要经验**：边界分歧往往**不改变骨架**（日主强弱、格局、用神、喜忌通常不变），
只改变时柱所属的个别神煞与六合关系。报告要明确写出「共有结论」与「分歧项」两类。

### 晚子时（23:00–24:00）：本技能**已有默认裁决，不再双盘**

详见 `references/zi-shi-dayroll.md`。要点：

- **裁决准则（优先于一切）**：「**一天没有两个子时。如果有第二个子时，那就是进入了第二天。**」
- 故 **23:00–24:00 出生者，日柱一律归次日**（23:55 与次日 00:10 本属同一子时，日柱必须相同）。
- **落地（两步）**：① 判「已过 23:00」→ ② **直接用「次日日期 + 原时刻」排盘**。
  复核：用次日 00:10 再排一次，日柱应相同。
- ⚠️ **技术陷阱**：`paipan.js` / `lunar-typescript` 的**默认是「晚子时算当日」，与本技能立场相反**。
  晚子时命例**必须显式改用次日日期**，不可直接采用脚本默认结果。
- **报告纪律**：开头写明裁决过程与采用的日柱日主，并点明为何必须裁准——日主之差会**连带改写
  时柱、调候主神有无、用神、相神、大运干支**，不是小修，是整盘重推。
- **裁决之后即定论**：全篇**不得再出现「若为某柱则…、若为另一柱则…」的悬置表述**。
  另一派之盘最多在附录列一张对照表备查，不计入正文推演。
  读者的最大确定性来自「一个明确的结论」，而非「两个并列的可能」。
- **（条件触发）**仅当用户**明确要求**双派并列时，才走 `zi-shi-dayroll.md` 四之二的**七项骨架不变量**四步法。

## 八、应期怎么推（这是实证推演最实用的部分）

命局的吉凶是**静态结构**；事件的触发靠大运与流年**引入新的地支关系**。做法：

1. 先列出命局四支本身已有的关系（合、冲、刑、害、会）。**若命局本身是「静盘」（无冲无刑无害），
   则一切事件必由运年引动**。此时**不可**直接把「第一个新关系」当作该十年的主题——那是第 4 层的东西。
2. **判大运，先走「四层权重」，顺序不可颠倒**（这是实证后补上的一条，起因是把重要的十年判反了）：
   | 层 | 看什么 | 权重 | 为什么 |
   |---|---|---|---|
   | ① | **用神／相神是否到位** | 决定吉凶**性质** | 《子平真诠·论相神紧要》「伤相甚于伤用」。相神到场，格才立住 |
   | ② | **日主是否得根** | 次高 | 身弱财旺之命，「能不能任财」全看这一步。禄旺之地有无，比多一个同类天干实在得多 |
   | ③ | **调候燥湿寒暖是否得解** | 次高 | 寒湿之局得火土则解，燥热之局得水润则解 |
   | ④ | **冲刑合害会** | **只作色彩** | 只改「血肉」，不改「骨架」；且要分清被冲被刑的是忌神还是用神 |
   **倒置 ① 与 ④ 是判大运最常犯的错误**（把刑害当主题、把相神当色彩）。
3. 大运干支与命局逐一求关系时，**地支之外必须另算天干层**：
   - 地支：冲/刑到哪一柱 → 该柱所主的六亲与事项受动；合/会成什么局 → 哪一行骤然增旺
   - **天干**：五合（合去／羁绊）、相冲（同性相克，力大且不留情）、**争合**（一字被两处合，力分）。
     运年天干与命局天干的关系**常是应期的直接扳机**——流年甲冲命局庚＝直冲财星／父星；
     大运乙合命局庚＝印星被合去。漏掉这一层，应期必缺。
   `paipan.js rel` / `full` 已同时输出地支层与天干层。
4. 流年在运的基础上再叠加一层，看是否**凑成完整的三合/三会/三刑**，或**填实大运所拱之字**。
   凑成／填实之日，就是该事项兑现的年份。
   （例：某月支与某运支**拱**出日主之禄／刃，而某一流年恰为该字——虚拱逢填实即成三合局，
   整运的峰值之年常落在此年。）
5. 对应到六亲：**冲克到某十神的位置，就是那位六亲的应期；同一时期另一个十神转旺，
   则另一位六亲安好**。两者一消一长同时成立，才算自洽。

**六亲应期的正确读法（结构示例，非任何真实命例）**：

设父星居月干（偏财）、母星居月令（正印）。若连续两年出现下列组合：

- 第一年：流年之支**冲年柱**（父母宫）；
- 第二年：流年之干与父星**同性相冲**（天干层，力大而不留情），同时大运之支冲动该运的库，
  旺者克金，父星两面受敌；
- 而同年**母星**恰因流年透干、又得地支余气为根 → **转旺**。

→ 判读要点：**「父星受冲」与「母星转旺」必须同时成立（一消一长）**，这套结构才自洽。
只写「某星受冲」而不查同期另一位的旺衰，属半截断语。

## 九、报告的固定纪律

- 结论先行，依据在后；每一条断语标出它落在 L4 的哪一步。
- 命中已知事实时，**注明这是「事后验证」**，不得表述为「事先预测成功」。
- 健康、婚姻、寿元类内容：明确写「民俗参考，以现代医学/法律/实际生活为准」。
- 不预言死亡年份、不给出「必死于某年」这类断语。只写「高关注窗口」并落到可执行的观察项。
- 命中率自述：梁湘润《八字务实研究》专章讨论「八字的准确率究有多少」——
  这类学问的精度上限在「十之六七」，凡声称百发百中的都不可信。

## 十、取用的五条精微规则

这五条都是「原技能没写、于是判错了」的地方。每一条都对应一次实际错误。

### 规则 1 · 用神五档，不能只写三档

原技能只分「用／喜／忌」，这会把**相神**抹平。正确的是五档：

| 档 | 含义 | 判据 |
|---|---|---|
| **用神** | 全局赖以生身／通关之字 | 「八字用神，专求月令」（《子平真诠》） |
| **相神** | 全局赖此一字**成格**者 | 《论相神紧要》「伤用神甚于伤身，**伤相甚于伤用**」 |
| **喜神** | 助用助相之神 | 顺用之 |
| **忌神** | 伤用伤相之神 | 逆用之 |
| **闲** | 不助不伤、略有益者 | 如燥土之于寒湿之局 |

**报告必须把这五档写全**——尤其「相神」与「闲」两档，漏掉必出偏差。

### 规则 2 · 比劫须分阴阳，比肩不充相神

- **阴干日主**（乙丁己辛癸）的比肩力量弱于劫财；阳干日主则两者近等。
- **比肩与日主同类，故不取为相神**。相神必须是**独立的、日主之外的**得力之字。
  例：丁火日主，忌神为庚辛金时，相神是**丙火（劫财）**而非丁火（比肩）——
  「再来一个同样弱的火」不等于药到了。
- 更进一层：**阴柔之火须以木为薪**。丁火无甲木则难久燃；若印星本已受伤，
  取丁帮身等于**分耗已经受伤的印星**。故此类命局**取丙不取丁**。

### 规则 3 · 「虚则补其母」，不可盲目补水

《滴天髓》「虚则补其母」。身弱时，生印之官杀（水）**不必然是喜神**：

- 若**印星已有力**，官杀可作「杀印相生」之源，属中性偏用；
- 若**印星已受制、母气本弱**，则直补水反生两害：**水多木漂**（印被漂而无法生火）＋
  **寒上加寒**。此时**补母（木）优于补子（水）**，官杀应列**忌神**。

**判别口诀**：先看印星有没有余力通关。没有余力，水就是忌神。

### 规则 4 · 同五行之内还要分阴阳、分燥湿

- **木**：甲（阳木）可为丁火之薪；**乙（阴湿之木）反伤丁**（《穷通宝鉴》「二月丁火，湿乙伤丁」）。
  若命局或运年中乙木被庚合、被辛冲，则**乙木到位形同不到**。
- **土**：湿土（辰丑）晦火生金，为**忌**；燥土（戌未）培木藏火、暖局去湿，为**闲**。
  一律列忌则过粗，会低估「戌未」之运。

### 规则 5 · 五行计数必须声明口径，且不得重复计数

- 推荐口径：**天干 1 分／地支本气 1 分／其余藏干 0.5 分**。
- **地支本气与藏干是同一物，只算一次**。「本气栏」与「藏干栏」并列的表格极易重复计数。
- 另可给一个最直观的口径：**八字本体（四干＋四支本气）**——它最能说明偏枯程度。

## 十一、实证规则的来历与常见分歧裁决要点

> 本节是**规则档案**，不是命例档案。凡来自实际推演的经验，一律只保留**结构**（十神、五行、
> 关系）与**规则**，**不保留任何真实命主的出生数据、四柱、私事与验证结果**。
> 见 `SKILL.md` 开头〈第一条维护纪律〉。

### 11.1 规则的来历（对应第五、六、七、八节与第十节）

这些规则都是「判错一次」换来的。记下**在什么结构上会犯什么错**，才能在新命盘上自动规避。

| 规则 | 触发它的结构 | 犯过的错 | 记取的教训 |
|---|---|---|---|
| 大运定性走**四层权重**（第五节、第八节） | 日主弱、印星当权而**财星三见透干**、命局为**静盘** | 把大运带来的**新刑害**当成了该十年的主题，遂把「相神到位的那十年」判成「有得有失」 | 第①层（用／相到位）定性质，第④层（刑冲合害）只作色彩；**顺序倒置必判反** |
| **官杀（水）的定性**（第十节规则 3） | 印星**已被财所伤**、无力通关 | 照「虚则补其母」把官杀列为「中性偏用」 | 先看印有没有余力通关；有余力才可用，没有余力则水即**忌神**（水多木漂 ＋ 寒上加寒） |
| **土的燥湿之分**（第十节规则 4） | 寒湿之局 | 把土**一律列忌** | 湿土（辰丑）晦火生金＝忌；燥土（戌未）培木藏火＝**闲而略喜** |
| **比肩不充相神**（第十节规则 2） | 阴干日主，运年再透一位同类天干 | 把「再来一个同样弱的同类」当成用神到位 | 相神必须**独立于日主**；且阴柔日主须以木为薪，取同类帮身反而分耗已伤之印 |
| **拱合必须算**（第五节、第八节） | 命局与运年两支夹拱一字 | 只认「中神在场」的半合，漏掉**虚拱**，峰值之年讲不透 | 拱出之字逢运年**填实**即成局——峰值之年最常出在这里 |
| **运年天干层**（第五节、第八节） | 运年之干与命局之干同类相冲，或合去所需之神 | 只算地支，漏掉干冲、干合，应期缺环 | 天干层常是**应期的直接扳机** |
| **五行计数口径**（第十节规则 5） | 表格把「本气」与「藏干」并列 | 重复计数，偏枯程度被放大 | 必须先声明口径，并**去重** |

### 11.2 常见分歧与裁决要点（可当裁决参照表用）

多版本比对（`SKILL.md` 第 9 步）时最常见的分歧类型，及其**既定的裁决方向**：

| 分歧项 | 常见两种说法 | 裁决要点 |
|---|---|---|
| **某十年吉凶** | 甲：以刑冲合害为据 → 有得有失；乙：以相神到位为据 → 最有力 | 以**相神到位为先**（《子平真诠·论相神紧要》「伤相甚于伤用」），刑害只作色彩 |
| **官杀（水）定性** | 甲：中性偏用（印可通关）；乙：忌神 | 先判**印有无余力**；印已受伤则官杀为忌（第十节规则 3） |
| **土的定性** | 甲：一律列忌；乙：湿土忌、燥土闲 | 分燥湿（第十节规则 4） |
| **同类天干的地位** | 甲：与劫财并列作喜神；乙：不作相神 | 比肩**不充相神**，阴干尤弱（第十节规则 2） |
| **同五行内部** | 甲：只写五行（木、火）；乙：分阴阳（甲／乙、丙／丁） | 必须分；且若该字在运年又被合被冲，则「到位形同不到」 |
| **某个流年的关系** | 甲：只提「禄／刃在何支」；乙：写出三合、拱合、冲刑害会 | 取**能解释「填实虚拱」**的那一版（拱合已入脚本） |
| **大运之干的合冲** | 甲：只写地支关系；乙：另列天干合冲 | 天干层必列；同一运若「合去用神」与「冲伤用神」齐发，**该运降等** |
| **五行计数** | 甲：干 1／支本气 1／余气 0.5；乙：分「本气」「藏干」两栏 | 以**声明口径且不重复计数**者为准（第十节规则 5） |
| **命宫、阴干羊刃、三刑名目** | 各本算法互异 | **属非主线项：只列口径、不作判据**。用户追问时，先说明本技能所用算法与来源 |

### 11.3 「重跑检查清单」（每次推演完自查一遍）

1. 判大运是否按「用／相 → 得根 → 调候 → 刑冲合害」**四层顺序**？有没有把刑害写成主题？
2. **相神**是否单列？有没有把比肩当相神用？
3. 官杀是否误判为「中性偏用」？印星真的有余力通关吗？
4. **拱合**是否漏了？（命局与运年夹拱一字的情形）
5. **天干层**是否算了？（干合、干冲、争合）
6. 五行计数是否**声明口径**且**未重复计数**？
7. 报告是否写全**用神／相神／喜神／忌神／闲**五档？
8. 六亲应期是否做到**一消一长同时成立**？
9. 是否写入了**任何真实命主的个人信息**？（见 `SKILL.md` 开头〈第一条维护纪律〉）
10. **静盘**（天干无合无冲、地支无冲）是否已在**命局自身**找局？还是仍在硬找岁运之冲？（见 11.4）
11. 命局自身已成的**三合局**是否写明「不待岁运」？（漏写会被误读为待运方成）
12. 起运 ≥6 岁的命，是否已声明**交运前只论流年、不排大运评分**？（见 `zi-shi-dayroll.md` 四之三）
13. **晚子时（23:00–24:00）命例**：是否已按「第二个子时即入次日」裁决日柱？
   排盘时**是否显式改用了「次日日期」**（而非直接采用脚本的「算当日」默认）？
   是否已用「次日 00:10 排盘应得同一日柱」做过自洽性复核？
   报告中**是否还残留任何「若为某柱则…」的悬置表述**？（有则不合格）

### 11.4 静盘／动盘二分（取象总纲）

推大运与岁运前，**先给命局定「盘性」**，三类的取象重心不同。
（**判据必须三档互斥**——旧版把「刑破害」同时写进动盘、又写进静盘的例外，自相矛盾，
实测会导致同一张盘在不同报告里被判成不同盘性。下表已改为互斥。）

| 盘性 | 判定（**按顺序判，先命中者为准**） | 取象重心 |
|---|---|---|
| **动盘** | ① 地支有**冲**，或 ② 天干有**合／冲** | 看刑冲合害的**「质」**——谁受损、谁得势、合来的是用神还是忌神。**有自发张力，不必全靠运年引动** |
| **半动盘** | 不合① ②，但地支有**刑** | 张力是**「缠绕」型而非「对撞」型**。实务含义：大事多不是「外来一击」，而是关系内部的慢慢拉扯——应期重点落在「何时化开」，不在「何时爆发」 |
| **静盘** | 以上皆无（**破、害只作轻者**，不改变判性） | **在命局自身找局**：本命是否已自成一局（三合／三会／拱），既成则**不待岁运**，其力量按命局论；岁运来时看是「填实」「引动」还是「冲破」 |

**一条自检**：判完盘性后自问一句——「这张盘会不会自己产生事件？」
会 → 动盘／半动盘；不会、须等外部来动 → 静盘。若你的判性与这句答案不符，回去复核①②③。

**要点**：静盘最忌用动盘思路硬找岁运之冲，会得出「一生平平无波」的误判；
正确做法是先认下命局里**已经成立**的那个局（哪怕它安静），再论岁运与之的关系。

**示例（虚构）**（四柱「乙亥 丁卯 己未 丁未」）： 天干无合无冲、
地支无冲，属**纯静盘**；而其**亥卯未三合木局全成于命局自身**（三支皆在四柱内），
不待岁运，且时支未恰为木局之墓（终） —— 故此盘虽静，木气之成实为命局核心。
（复算：`paipan.js rel "乙亥 丁卯 己未 丁未"` 只报「亥卯未三合木局」，无冲、无合、无刑害破。）
